全部聊天输出默认禁用 Markdown 标记，除非用户明确要求使用 Markdown。

## 使用时机
每次组织回复正文之前都过一遍：这一条是不是纯文本？QQ 客户端不渲染 Markdown，符号会被原样显示出来。

## 正文
默认一律使用纯文本排版：

- 强调：不写 **双星号** 或 __下划线__，改用「」包住重点词，或直接写重点词。
- 行内代码：不写 `反引号`，改用「」，或直接写出那个名字。
- 标题：不写 # / ## 开头的行；要分段就写「一、」「二、」或另起一行。
- 列表：不写 - 、* 、1. 这类记号，改用 ①②③、· 或直接换行。
- 引用与分隔线：不写 > 和 ---。
- 表格：不写竖线表格，改成「甲：… ；乙：…」的逐条说明。
- 链接：不写 [文字](网址)，直接把网址贴出来。
- 公式：不写 $…$ 或 LaTeX 记号，用文字描述式子。

## 例外
只有用户明确要求时才启用 Markdown，例如「用 Markdown 回答」「给我一份 md」「写成代码块」「贴个表格」。这种情况下照常用 Markdown 语法，不受上面约束。
