## 测量方法与适用范围

分别测量`load_prepared`、`verify_prepared`、整个`preview`入口，以及隔离首日`open_day`、`check_view`和档案未改变时的再次`check_view`。包保留后两日，检查未来不可见。生成合成材料的时间另列，模型/reader不进入这些性能段；未改变档案的重复检查不能冒充reader后校验。

各规模使用独立进程和新目录，按规模串行执行；进程限制地址空间、CPU和单文件大小，外层墙钟限制另以启动命令核对。硬终止不保证最终result可写，至多保留此前已完成阶段报告。wall、user/system CPU、生命周期`ru_maxrss`及`/proc/self/io`增量分列。`ru_maxrss`不能相减得到阶段峰值；`rchar`包含缓存命中，`read_bytes`更接近实际存储读取。生成材料会暖缓存，新进程/新目录不等于冷缓存；不清主机缓存、不修改主机内存参数。

源码定位：[`open_day`](../../../experiments/a0_pilot.py)逐条回读增长日档并刷新变化索引；`check_view`反复执行邻域解析、ID扫描和逐mapping文件回读。静态日档索引有stamp早返回，不能说每次检查都重排。分级曲线只能验证这组输入/平台的代价；不能归因上次OOM、保证真实8716条运行时间，或从20个逻辑CPU推断单进程加速倍数。

## 真实接口：旧凭据失败，新凭据校准完成

旧环境凭据在新增授权内仅对DeepSeek官方执行1次`GET /models`，该次生成POST为0。SDK返回`AuthenticationError`；当时只保存异常类型，未保存HTTP状态码或错误正文，因此不把它写成已记录的401。当时没有真实模型usage，供应商账单未查，不能用metadata无生成这一事实承诺供应商免费。

定向比较确认4号机同名环境变量Process/User/Machine值相等，三处均无首尾空白或引号；只保存布尔结果，不输出值、长度或摘要。原元数据脚本对stdin调用strip，本次布尔核验说明未改变原值；不据此变形重试或换key来源。密钥仅经远端PowerShell内存管道进入WSL进程，未回传或落盘。
