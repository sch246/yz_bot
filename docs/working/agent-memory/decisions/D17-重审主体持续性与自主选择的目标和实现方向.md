## 2026-10-20 Cortico参考重点校正：统一事件与输出

维护者指出：“Cortico的特点难道不是统一事件流和输出流吗”。主代理此前突出持续运行／再醒，漏掉更基础的跨环境结构。复用只读研究代理定向补证，主代理亲核固定版本 types.ts、core.ts、loop.ts、Cormini outputTap 及 QQ 发送／回录，已修订[研究稿](../agent-memory-reference-update-20261020.md)与地图。

当前实现：多个World共用事件封装、事件库／总线与主认知循环，保留来源和cursor；外部事件有共同上下文承载。模型输出使用StreamEvent／OutputTap接口，Cormini将其扇出至已挂载World接收器；World另以工具执行行动、把实际回执交回session，QQ显式回录qq.self。因此“统一事件输入与输出通道”是更基础的参考点，再醒只是其中一种事件来源。统一不等于所有输出自动回录，也不是现实时间严格排序或单个耐久双向流。

这是对先前研究概括的校正；D17持续系统目标保留，不选择整套World／Persona架构。原型先核现有多窗口、行动结果和时钟接点已统一的部分与缺口，再划切片；T12未验证checkpoint、T13草案及既有生产边界均保留。本轮仅公开代码和文档核对，无模型／凭据／生产访问。以下原研究、答案与全部历史完整保留。
