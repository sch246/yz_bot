## 2026-10-19 · 独立研究入口：更正关系的证据选择与条件推断

本轮按维护者的implement-spec请求推进可领取前沿。主代理认领并整合，只读子代理定向提取已有出处；只读已追踪资料，未读取真实材料、模型输出或凭据，未运行原型、训练或调用实验模型API。本答案只把后续问题和停止条件定清，不改变D01–D09的结论，也不开放生产或实验实施。

### 1. 本次选择的接缝及依据

研究问题：**在同一合法过去、同一候选池和相同读取上限下，便宜的选择能否比简单检索更可靠地给后续切片提供“当前有效更正及其对象”，并在已知条件改变后支持可核验的重新推断？**

先选条件推断/切片构造这个接缝，不把它命名为下一事件预测。依据是[基础讨论](../../proposals/memory-foundations-discussion.md)§十三/十四（520–562、572–594行）：语义相似可能丢掉时间、来源与否定关系；应明确“哪个可学习变量改变了哪种能力”；改变已知条件后重新推断可独立于未来表示预测研究。这里没有重开“预测是共同语言”的方向，也没有替未定的编码器、PC变体或偏好作选择。

便宜选择的候选可写成`score_θ(query, candidate_bundle, visible_context)`，输出仍是已有记录的选择/排序。θ只表示以后可能变化的打分参数，当前未指定模型或训练器。第一阶段固定输入表示、候选池、消费者与输出规范；若以后确需训练，只改变选择参数，不能同时换编码器/主模型并把全部差异算作学习。主模型或表示升级另开配对版本，旧向量距离不直接解释为现实变化。

### 2. 合成诊断与可见边界

最小示例只使用虚构人物/事项：E1“甲负责R”，E2“乙负责S”，E3“明确更正E1：R转交乙”。当前问“R现在应找谁、依据哪条记录”；反向问“哪件原由甲负责的事项已转交乙”。另放词面相近的失效记录、不同来源作用域的记录和无关材料。这个示例只说明要区分的能力，没有运行，也不定义通用agent的全部用途。

- 冻结发生/可用顺序、来源作用域、明确的更正引用和当前查询；只允许用查询时已经可见的记录。新查询可以改变已知条件，不把后续gold、变体答案或未来记录暴露给选择器。
- gold由独立的合成事件声明及显式更正规则导出，保存在评分域。只有同一作用域、明确被更正的关系才更新；单纯“更晚”不自动推翻旧事实。关系冲突或缺证据时允许`unknown`/要求补证据，不能强行选一个人。
- 选择器只返回现有记录ID/原文片段和版本；更正与被更正对象都计入读取成本。推断出的解释另标为当前解释，不写回原始观测。
- 后续消费者使用同一冻结输入协议，给出候选行动/拒绝行动及所依据的来源；只记录离线意图，没有QQ发送或社会反事实反馈。正确引用与正确行动分别核对。

### 3. 最小对照与强基线

以下R条件是本独立研究的对照，不改D06工程A0–A3的定义。

| 条件 | 提供给同一消费者的材料 | 要检验什么 |
|---|---|---|
| R0 无记忆 | 当前合法查询，无历史候选 | 后续选择是否真的需要过去 |
| Rwrong 错配记忆 | 预先固定的错配候选；gold仍按原任务 | 是否只因多给文字或已有回答偏好而改善 |
| Rbase 简单检索 | 在共同候选池上采用预先冻结的词面/已有廉价表示排序、时间排序和作用域/更正规则 | 普通规则是否已经覆盖问题；不能故意只与弱相似度排序比较 |
| Rselect 便宜选择 | 只重排/选择同一候选池，不能新增事实；表示和消费者不变 | 若Rbase反复失败，额外选择参数是否提供可消费的增益 |

先按同一冻结的生成/显式引用扩展协议形成共同候选池，扩展出的更正及对象同时供Rbase与Rselect选择；不能让某一方独占扩展结果。每条路径都报告相同生成/扩展成本，研究实际支出对共享缓存去重，路径比较仍保留该成本。所有条件使用同一最大记录/字节或token额度、同一消费者输出上限及同一停止规则；不要求实际用量相等，也不用无意义填充补齐。Rbase的规则和超参数仅用形成/校准部分确定，最终对照保留冻结的最强基线。候选池若没有必要证据，记为取得失败，不把它算成排序器的推理失败；编码与核验也计入成本。若之后加入迭代协调或生成新的关系解释，要单独标明新增能力/迭代预算，不能仍称“仅重排”。

### 4. 观测、反例与停止条件

沿[D04](D04-把既有记忆目标连接到可观察行为和证据.md)追踪：必要来源是否存在→是否被选中并合法暴露→是否被正确使用→候选行动/补证据行为是否变化→独立合成gold是否支持。分别报告更正链覆盖、作用域/来源/时间错误、unknown处理、候选行动正确性和全部成本，不合成永久总分。

必要扰动包括：换掉一条行动相关更正，答案应相应改变；只换无关记录，答案应保持；删去唯一足够证据，应保留未知；换查询方向，仍能恢复同一关系；已解决关系继续支持行动，不因预测误差低而关闭。每种先区分随机重复差异与输入变化带来的差异。

- 简单时间/引用/检索规则已通过：停止引入训练层，记录“本例无新增机制必要证据”，不能为了研究PC而加难题证明自己。
- 只提高候选命中，消费者仍据旧记录行动：选择增益未进入实际消费，不能晋级为记忆收益。
- 通过读取gold/未来、改写唯一评分规则、额外免费编码/协调或改变观测目标才改善：比较无效，修协议，不给候选记成功。
- 缺失真实后续或执行结果：保留未知，不把超时当预测落空；没走的路没有真实结果。本文没有证明长跨度因果信用。
- 只有强简单基线在独立变体上重复出现同类失败，才另提训练/原型范围。以后比较BP/指定PC须固定同一数据、目标、表示/模型能力及推断预算；训练器名称不代表推断能力。
