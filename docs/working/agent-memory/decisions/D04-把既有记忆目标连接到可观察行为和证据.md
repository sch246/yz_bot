## 已完成研究答案（从本轮原提交内容恢复）

结论：既有目标可以连接到以下可扩展诊断覆盖。它们不是五个独立系统，也不是把理想agent限定为几道题；来源是基础讨论§二/三、stateless§1/8与研究地图。未选择永久总分、容许退化或费用。

| 既有目标 | 希望过去怎样影响现在 | 可用历史与对照证据 | 离线结论边界 |
|---|---|---|---|
| 连续感 | 知道刚才发生什么、自己正在做什么；分清发生/阅读/行动时间，正确接上同一轮及跨唤醒事项 | 逐时回放、先后/时间间隔/来源探针，含自己的意图与真实回声；同一时点A0–A3成对比较 | 模型没看见与看见后遗忘要分开；不能把旧171-call基线当当前版本，不能假设加时间戳已解决全部原因 |
| 对世界的了解 | 取回人/群/关系/事实及其变化，接受更正，区分原话、玩笑、推测和当前有效解释；不把私聊内容错送别群 | reply/明确纠正的机械候选、独立来源核验、多人物/主题入口、低频精确事实、过期/错配笔记对照、窗口/来源检查 | 真实chatlog能核对发生与证据支持；旧昵称/私聊缺失字段不能补成确定身份。跨窗口需要新冻结材料，旧单群样本本来不覆盖 |
| 技能 | 真实失败形成可加载做法，后续少走重复错误路径；条件改变时停止套用 | 既有大范围反查失败作已见练习，运行产生的笔记/Markdown候选hash、后续精确加载、实际路径/引用、去候选或补证据对照、未见复验 | 写入/加载/改善分开；理论可达不等于有效召回；linked路径收敛仍可能证据外扩写；一次随机消融不是确定因果 |
| 自我 | 延续身份、在乎的事和已承诺/未完成意图；知道做过、没做、结果未知与后来撤回的区别 | 行动记录+工具结果+候选回声+全局hint的来源链；承诺在合法后续事件中兑现/落空/未知的状态检查；跨唤醒接续与纠正 | 旧回复的参与者反馈只能评价旧轨迹；没有执行结果不能判承诺兑现，超时无观测不等于失败；离线不证明人际信任或满意度 |
| 学会学习 | 诊断、选择实验与形成改动的方法本身能改善，避免只有固定prompt被调好 | 任务层闭环先积累摩擦；以后让旧/新改进方法面对未参与形成的新失败，以相近预算比较其候选的独立表现 | 任务表现更好/图书管理员写得更多/主观自评均不能证明元层改善；当前尚不具备完整协议，不作本轮替换必要门槛 |

横贯诊断：材料是否存在→是否被选中/合法暴露→是否被正确引用/使用→行为是否变化→独立结果是否支持；引用了正确原文仍须查具体断言，减少调用仍须查事实与任务接续。原文、来源和上一版本/墓碑保留，删除笔记后是否再次需要有跟踪；低使用频率不作删除依据。

近期首轮针对维护者已报告的“忘刚刚/时间顺序”和token成本，并覆盖更正、跨窗口、承诺及经验消费。这个顺序是当前已报告问题的研究起点，不是重新替维护者排序全部人生目标。采用/取舍仍留给验收票真实交流。

旧材料可直接复用：连续三天/七天保留窗口的选样决定、自动候选/独立核验/每题分叉经验、语义下一跳与证据外具体化反例、checkpoint/fork与预算失败记录。不能把4道校准题当正式完整题库；不要求人工通读聊天。新提案人工探针与旧自动标注口径差异交验收票处理。

尚不能由固定历史证明：候选新回复的社会反事实、长期关系改善、无上限学习、通用预测奖励和所有未来用途。可观察新回复/意图的内部一致性，但真实参与者反应须以后合法的新外部证据；不从旧chatlog虚构。
