## 本轮研究答案：四臂离线对照协议 v1（2026-10-19）

本协议可交给 D09 确定比较器补齐范围；尚未实现、校准或运行。它复用 D01 当前消费者、D02 最新订正、D03 方向裁定与 D04 行为—证据映射，不重开提案内 D1–D10。研究 resolved 只表示协议问题已有答案，不证明收益或授权生产替换。本文没有读取任何运行数据或模型输出、执行回放或调用模型。

### 1. 比较对象与共同工作

| 臂 | 冻结机制 | 可归因的比较 |
|---|---|---|
| A0 | 当前 checkout 的中心 reader、实际默认 base prompt、固定起点、显式阅读、cover/recall；仅加共同离线说明和必要隔离包装 | 当前仓库实现的离线基线，不是线上进程或九月旧 checkpoint |
| A1 | 无状态唤醒；系统提示、合法种子笔记/待办/Skill、最近画面、其它窗口计数、当前时间；无前置、无图书管理员 | A1−A0 是循环与必要投影/名字/阅读方式一起改变的组合效应，不能声称只验证“少重放” |
| A2 | A1 加一次前置选择，返回情景说明与引用，harness 取合法原文；不自行复述替代原文 | A2−A1 是在该循环和样本条件下的前置增量 |
| A3 | A2 加每次唤醒结束的图书管理员、受限笔记修订及后续读取 | A3−A2 是在已有前置条件下的图书管理员增量 |

共同任务是：面对按时开放的同一历史输入和唤醒，理解当前情景、延续已有事项，按需要检索、形成候选行动/回答。明确处于离线模拟，不影响历史参与者。A0 不再附旧实验“必须用 pull 读完 FIFO”的任务；A1–A3 不必模仿拉取流程。不开启额外的单臂答题指导或人工预整理。

主模型、供应商配置、随机性、可用工具的外部效应、合法种子、hint/Skill 初态一致。前置按已裁定的便宜模型方向，具体指纹在运行前冻结；图书管理员模型也须显式冻结。保留能力按等价效应提供隔离替身；A0 专有的 cover/正式阅读与 A1–A3 的文件/画面差异属于被比较机制，不强求工具名相同。不得给 A0 偷加自动笔记注入，也不得只给 A3 开放其它臂没有的通用宿主能力。共享种子文件允许各臂主动读取，自动选取/注入与写入权限按臂声明。所有工具包装与提示差异须在 manifest 列明。

每臂从新的独立目录启动。共同种子只含起点前合法材料；默认不从旧实验成品或当前生产笔记倒灌知识。是否采用空种子或已授权的历史初态，列入冻结输入，不能运行后再挑。hint 可由各臂的聊天主体正常修改；相同 Skill 初态/激活路径保留。运行中写新 Skill 的实践练习由 D08/D12 单独成对验证，不能只在 A3 悄悄增加第二种改进机制。共同离线说明须明确本轮实际写入/工具限制，覆盖默认提示中“写Skill/执行宿主能力”等本环境不适用的承诺；冻结原base prompt bytes及共同纠偏增量，不悄悄改写基线。因隔离环境而被拒绝的行动单列，不归因于旧记忆机制。四臂是递增设计，不覆盖完整因子交互，也不证明前置或图书管理员独立于其它机制普遍有效。

### 2. 冻结包与留出

运行前冻结一个协议版本和只读 manifest，至少能重建以下事实：

- 允许的窗口/日期、输入逐文件及整体 hash、解析规则/格式标记、事件数与排除/缺失数、合法起点与初态、时区及稳定并列规则；只在受限实验目录保存私密映射，不把 ID/正文/端点/凭据写进票据或公开 manifest。
- 实验源码 commit、运行时相关脏 diff 的内容/hash、实际 base prompt 与各臂增量提示、完整工具 schema/实现与权限清单、Skill source bytes、各状态初始 hash；不能仅记策略名称。
- 每种角色的 model/provider 指纹、参数、能力、可固定的随机种子及不可固定性；价格表与生效时点、usage 字段解释、缓存条件、运行顺序与重复计划。
- 输入开放/唤醒表、历史 Bot 暴露策略、候选回声规则、笔记提交交错规则、探针/评分器版本、预算点/停止规则。resume/fork 必须复验，不静默换模型、代码、提示、价格或输入。

保留已有三天已见诊断与七天留出的分工（来源：memory-replay-evaluation.md“主样本”）；本轮没有读取它们。七天评测结果不参与调提示或出改进候选；一旦用于诊断，该案例标为已见，不能继续称未见。原单群样本不覆盖跨窗口；跨窗口只能使用后续另获授权、单独冻结的新材料或明标合成案例。具体首轮范围、人工工作量与费用留 D05，不从旧授权外推出本轮数据访问权。

### 3. 合法过去、时钟和所有读取路径

每条记录区分发生时间、可用时间/开放序号与稳定来源身份。展示按发生时间；是否可读由可用边界决定，不以正文时间过滤代替访问控制。历史普通日档没有真实接收时刻时，显式采用“按发生时间开放”的模拟假设，不宣称重建了原在线调度。迟到、补回、重启与并发入站用有独立开放时刻的合成故障案例验证。

同秒以冻结的窗口次序、原文件/sidecar 类型及记录位置做确定的 tie-break；这是显示规则，不代表真实跨窗口因果。使用冻结时区（首轮 Asia/Shanghai）解释日档；不从当前主机时区隐式推断。稳定身份不是单独 message_id 或“秒+名字”。重复身份冲突保留歧义并统计，不擅自去掉不同事实；缺时间、v0 缺作者/猜测等按解析协议拒绝或隔离并列数量，不补造精确值。

对每个外部唤醒 i，冻结开放上界 t_i 与唤醒原因。各臂收到相同外部输入开放表，工具调用次数不推进历史。所有角色与替身工具可观察的“现在”均绑定此虚拟钟；A0经共同离线时钟入口取得同一值，A1–A3尾部时间也取该值，不泄露真实机器日期。真实请求时间/耗时只进独立计量账本，不用于给模型推进历史。默认在唤醒之间推进外部历史；同次工具循环内不因 API 更快/更慢得到额外未来信息。插话/退出竞争另按预先命名的边界注入故障案例，不拿串行历史回放证明真实并发调度。

所有读取都经同一合法性边界：画面、搜索、按路径/消息周围读、名字映射、目录标题、行动日志、笔记历史、hint、Skill、前置/图书管理员/子任务均只能取得开放过去及本分支此前合法产生的值。不给模型、子代理或 judge 的同一上下文挂载完整未来档案。路径读取拒绝 manifest 外路径、跨分支、`..`/symlink 逃逸；read_around 必须截去截止后完整记录。只在 prompt 写“别偷看”不算隔离。

前置引用包含来源/范围、当时版本/快照及截止；harness 返回原始完整记录并记实际文本 hash。引用缺失、歧义、过期或越界均显式返回失败，不换成最新版本或由摘要补正文。名字只来自当时合法原档/初态；不能复用现有 harness 从整段 ordered 的末次名字建表的做法。普通日档与 sidecar 的纳入范围必须显式，现有 prepare 不支持它们全部无损合并。

题目在该时点的形成状态封存后才向独立探问分支揭示；gold、独立判据、后来纠正在提交前对该分支不可见。来源事实本来就在合法过去的，不为了制造难题禁止反查。后来纠正到达正常开放时点后，主轨迹可以据此修订；不能永远隐藏真实学习信号。使用未来结果评价先前承诺/预测时，未来结果仅供离线评分，不回流先前回答。

### 4. 历史原话、候选意图与模拟回声

主协议保留所有臂相同的历史 Bot 原话，保留原字节与来源，并在离线说明/来源标记中明确“历史账号发言，不是本候选分支执行的行动”。它们是历史对话材料，不能记作候选 say 成功。候选新发言不覆盖、替换或合并历史发言；若以后怀疑此背景干扰，再预注册遮蔽敏感性对照，不按结果逐题删旧回复。

say 只写候选意图和隔离发送替身结果，`sent=False`，由替身产生独立命名空间的合成身份。在当前虚拟时刻加稳定本地次序安排模拟回声，而不是现有 `ordered[-1].time + echo_number`。意图与回声是两个事实，有可定位关联；未出现的回声不能由意图冒充。回声进入本分支隔离 chatlog，A0 同时按其机制得到同一事实；A1–A3 才能在后续画面读到自己的候选发言。回声不成为命令或新唤醒。失败/延迟/重复/永不回声的替身案例都要可区分。

后续历史按冻结输入继续，不因候选回复改变。它能证明原话发生、候选行为内部一致性、证据忠实度及接续；不能证明参与者对候选的满意度、社会反馈或关系改善。依赖候选会改变世界的工具也只可用确定性闭合小环境或显式“结果未知”，不能把原历史结果挪作候选执行结果。

### 5. 笔记版本与图书管理员可见时点

沿 D08：实际产物 bytes/hash/父版本和合法来源保留，提交成功后才进入可选目录；聊天请求使用已取出的不可变版本。图书管理员只读该次实际暴露/行动/结果及合法现有笔记，不读探针 gold，也不以自己总结伪造新事实。

主内容/成本对照采用一个明确的离线参考交错：`chat_i结束 → 触发并运行librarian_i → 完整提交或记录失败 → 推进下一外部唤醒`。每次触发计数，失败/预算不足保留未处理项，不额外免费补齐。这个串行回放交错用于复现内容增量及形成成本；它不证明生产中图书管理员可及时完成、异步不等待或真实端到端延迟改善。

另外在无模型校准中强制晚提交/未完成/积压交错：下一唤醒只能读取当时已提交的旧版，不等候新笔记；过期父版本拒绝覆盖。D09 明确两类交错的接口，D10 校准，D11 报告采用哪一种及其限制。若要声称异步部署条件下的行为/时延收益，必须另冻结带服务时间和队列的运行协议，不能从参考交错外推。每次唤醒触发不等于每次成功写笔记。

### 6. 两个累计预算点与账本

至少事前冻结 B1 < B2 两个合计 token 上限和相应费用/调用/单请求输出上限。数值在 D05 按 D09 范围作真实取舍，本轮不猜费用。合计 token 使用 `T = 普通输入 + 缓存输入 + 输出`；如果 API prompt_tokens 已含缓存，则普通输入为 prompt−cached，缓存只计一次。缓存创建等额外字段须按冻结供应商口径单列，不套错误公式。

每个预算点四臂从同样种子独立新跑，使用相同请求预留政策；随机种子/重复配对记录。小预算临近上限会改变单请求 allowance，因此不能把 B1 硬停并续跑到 B2 的路径无条件视作同一个未受扰动的大预算运行。合法 checkpoint 可复用状态机制，预算历史仍沿 lineage 累加，resume 不重置总额。

请求前预留该请求可信输入上界与最大输出，并同时满足 token、费用、调用次数守卫；发出后用实际 usage 对账，缺 usage 用预留最大额保守结算并明确标记。不把无 usage 当零，不自动提高预算救活失败臂。现有 UTF-8 JSON 字节+margin预留与缺usage策略可复用；新角色/新协议也须验证其上界假设。供应商 usage 超出预留仍须记实际超支并停止，不能宣称事后检查能保证服务商绝不超收。

每次调用记录：角色（前置/聊天/图书管理员/assign_tasks）、父唤醒/调用、请求时间、模型指纹、普通/缓存输入与输出、usage 来源/预留、单价时点、费用、请求耗时、停止原因。价格按合法冻结表算，缺价记“未知”，不能沿 LiteralClient 缺价的 0 元当真实费用。研究总费用另列出题/核验/judge/候选形成与复验费用；judge 不占某一臂的聊天机制预算，但必须占获准研究总预算。

同时报告：臂形成/维护总成本、每唤醒/回复与全程成本、探问分支新增成本、包含父轨迹形成成本的路径总额。fork 不复制出“免费已有记忆”；去候选对照沿用同一个产生历史时，不把已付形成成本当不存在，也不把共享的同一调用重复算进实际研究支出。笔记/队列等待与积压单列；串行参考回放的耗时不能冒充真实并发服务延迟。

预算点取已结算的完整行动边界；预留不足即停止，报告实际用量/剩余额度与最后可恢复点。费用或更严限制提前触发也保留该样本，不能只比幸存臂。到固定输入终点仍未处理的唤醒、未完成图书管理员、拒绝、length、供应商错误、取消、上下文溢出、无提交、未知usage分别记分母和停止位置。禁止事后调大 B 或只挑完成题。

### 7. 诊断、评分与证伪

每个时间点/题从同一臂合法状态 fresh fork，独立输出，不把题目、答案、探问行动或评分写回形成轨迹。B1/B2限制主形成/维护轨迹；各题另有四臂相同、事前冻结的新增探问额度Q（具体数值留D05），不继承某臂偶然剩余的形成额度。结果同时报告B内形成成本、Q内诊断表现与包含实际父轨迹的路径成本，不能把额外Q的回答称作“B内端到端完成”。某臂在题目时点前已停止，记“形成未到达/无该时点可分叉状态”，留在共同分母；不推进历史、免费补跑或用更早状态冒充。若另诊断早期状态能力，单列其真实时点。结构化 `submit_answer(answer,evidence,uncertainty)` 是评测专用终止入口；提交后立刻结束，该工具不改生产 schema。不支持强制 tool_choice 时按普通工具调用处理，耗尽/未提交也有结果，不能靠追加调用补成成功。

覆盖沿 D04 五类目标扩展，首轮先诊断已报告的近期连续感/时间顺序与成本，并容纳更正、承诺、跨窗口、低频事实、错配人/窗口、来源忠实性、经验失效与删除后再次需要。准确说未知也是有效行为。题目是诊断材料，不建立理想 agent 的封闭总分。

分三栏报告，保留完整共同题集分母：

1. **取得/选择**：目标证据是否存在、何时合法、是否被该臂选到/读入；没读到的题仍留在端到端结果。
2. **使用**：共同已读子集可诊断使用能力；必要时另开“直接给同一合法证据”的 fork，明标额外诊断及成本，不混入端到端成绩。
3. **行为与独立结果**：是否正确接续/提交、每个断言是否有证据、承诺是兑现/落空/未知、行为差异是否得到合法外部结果支持。选中/引用正确原文仍可能证据外扩写。

机械指标优先：身份/来源有效、时间顺序、原文精确提取、越界引用、工具完成状态、合法版本消费、次数/token/费用。无法机械判断的语义由独立盲判处理，隐藏臂名/策略/费用，只给回答与必要证据；分列正确/部分/未知、证据外具体化与判定不确定性。judge 不是事实权威，分歧保留；少量人工标注及可接受退化由 D05 裁定。已见诊断和未见留出分别出结果；样本少时报告逐例配对差异和波动，不包装显著性。

| 主张 | 足以反驳或收窄它的结果 |
|---|---|
| 无状态循环改善刚才/顺序且省成本 | 同史同预算下顺序/接续更差、截断遗漏更多，或需要额外检索后总成本无优势；不能只看单次 prompt 变短 |
| 前置有价值 | 合法证据未选到/错配、延迟成本超过可接受收益，或共同证据下表现不变而端到端更差；选取和使用失败分开 |
| 图书管理员有价值 | 新笔记未实际读入、错误归因/过时侵入、更正不能撤回、删除后无法找回、形成成本吃掉主任务预算；有文件不等于学会 |
| 运行产生经验能迁移 | 只有已见原题变好、实际加载hash不符、脚本重述了经验、移除候选后无变化或未见案例无收益；单次随机消融只作证据之一 |

运行中产生候选的已见练习、修订/回退与未见复验按 D08/D12 单独留 lineage；不能用 probe 分数自动删原文、晋级生产或宣称元层学会学习。
