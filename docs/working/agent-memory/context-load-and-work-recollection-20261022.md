# 降低上下文负担与工作细节找回 · 研究提案

2026-10-22维护者提出：上下文整理服务于更低的认知负载；场景不只聊天，例如让大肥鱼完成工作，主体留下少量印象，追问时仍能找回细节。本页是讨论提案，没有新增生产实现、数据读取或模型调用，也没有裁定具体结构。

维护者随后明确目的：“让每一段上下文都有归处，每一段上下文都有来处”，避免不相干内容占满上下文；进一步纠正：任务边界、切换、保留比例是前置agent按当前处境重新选材后表现出的现象，不应先被规定为状态机、相似度公式或固定分类。认知改变，选材和寻找线索也可以改变。A与B只是便于观察的例子，不要求运行时认识任务标签。

当前接手计划见[T28](tickets/T28-让前置选材决定实际上下文并支持过程重选.md)。本轮只发布已有实现与计划，未实施该票。编码器、可交换与规约性质仍是可探索方向，不成为先行建设或验收的替代品。

当前上下文只承载正在理解、选择和行动所需的材料。长期保存不意味着每轮注入；工作印象本身也按当前关注选择。降低负担包括少找资料、少解歧义、少重建关系，不等同字数越少越好。适度展开可能增加字数而降低推理难度。

## 来处、归处与当前是否需要

- **来处**：原消息、工作产物、工具结果或自身已作出的判断，有可定位来源；派生内容能追到依据，不拿后来的重建冒充当时的决定。
- **归处**：材料离开当前上下文后仍有可找回的位置和关联，可继续、追问或修订。无需强制唯一分类，同一材料可以被多件事共同引用。
- **当前是否需要**：进入或留在这次上下文，应能说明它与当前目标、问题或实际依赖有什么关系。有来源、有归档不等于应该继续注入；“刚刚发生”本身不构成永久保留的理由。

前置按当前处境和已有理解选材，未选中的内容仍留在原处；不需要额外的退出／归档动作或显式任务切换。两次选材的重叠可表现当前理解下的相关性，不先计算一个相似度再规定保留比例。在A／B例子里，无关的A细节不因刚刚出现而固定注入；局部依赖则能被取回。选择可以包含合理探索，不用事后是否引用来强制解释每一段。保留承诺或判断的历史，也不等于让它们的全文常驻。

来源与归属的追溯信息可以留在日志／索引里按需查看，不要求给模型看到的每段正文再包一大块元数据。要同时解决可追溯与退出，不能把“有出处”或“已经写摘要”当作上下文已清理的证据。

## 可借用的机制，不预定认知分类

- 原始记录与产物保留可定位的出处，包括实际请求、派发、结果、版本及核验。子代理结束或自称完成不自动证明任务完成。
- 经历可沿既有owner、请求、结果和产物找到；需要时增加链接或线索，不另造可写任务真相源，也不要求每段先成为一个任务对象。索引与派生摘要可重建；主体采纳的理解、承诺和选择保留其形成／修订记录，不把重新推断当恢复。
- 主体形成自己的印象：发生什么、为何与自己有关、以后什么情况下值得想起；他者报告和自身理解分开。印象可以变化，不把单次表现固化成人格事实。
- 当前画面按当前问题选择少量印象及正在使用的细节。问“做了什么”读概况；问“为什么”读决定与理由；问“怎么做的”读对应改动／步骤；问“真的成功吗”读核验原件。缺少记录就明确不知道，不从摘要补造理由。
- 工作入口可通过项目、人物、产物、别名及主题找到；允许同一工作多个入口和跨工作链接，不强迫唯一层级。先用普通文本／已有索引验证需求，向量检索并非结构前提。
- 写入时留下以后可能被用到的线索，是对未来使用的预测；前置未来能否找到它，提供修正线索。完成、中断或追问只是可能影响选材的处境，不规定固定切段或折叠触发器。已有笔记、链接与Skill可继续使用，不要求每项经历提炼规则。

示例（假设）：大肥鱼完成网站相册。当前只见“相册有可用版本，手机端尚未核验；工作W42”。入口按“改了哪些文件／为什么用缩略图／如何核验／仍缺什么”定位相应原件。没有提到相册时，W42也不必常驻。一次谈话、失败或关系经历同样可以有符合其意义的入口，不必都采用工作字段。

## 跨领域证据与推断边界

- [Wegner、Erber、Raymond，1991，Transactive Memory in Close Relationships](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner%2CErber%2C%26Raymond1991.pdf)：区分细节与“谁知道什么”的目录；原文有真实情侣／临时配对的记忆分工实验。借鉴保留寻找路径，不能推导AI能恢复任意细节。
- [Furnas，1986，Generalized Fisheye Views](https://courses.ischool.berkeley.edu/i247/f05/readings/Furnas_GeneralizedFisheyeViews_CHI86.pdf)：局部细节与全局地标并存。借鉴按当前问题展开，远处仍留足定位；不能按距离删掉关键约束。
- [Altmann、Trafton，2004，Task Interruption](https://interruptions.net/literature/Altmann-CogSci04.pdf)：人类资源分配任务的中断／恢复与准备线索实验，效果受准备条件影响。借鉴保存停在哪里、下一动作和相关对象，不能把人类恢复秒数移植为模型收益。
- [Kirsh、Maglio，1994，On Distinguishing Epistemic from Pragmatic Action](https://doi.org/10.1207/s15516709cog1804_1)：特定交互任务中的动作可帮助获取信息、替代心内计算。借鉴明确查状态与廉价探针，不能推导任意工具调用都有益。

上述原论文由只读子代理定向阅读；设计迁移均为待验证推断。主代理网页工具本轮对前两处PDF再次抓取超时，不把其当作自己成功重新抓取。

## 最小实验方向

定向只读核对当前源码：[Center._freeze／_run](../../../mods/chat/center.py)按近期数量选默认正文，每次主唤醒新建Chat；[cognition.select](../../../mods/chat/cognition.py)明确近期画面与当前笔记不可删除，只能补选；[LLMClient.chat](../../../mods/llm/__init__.py)在同醒工具循环里持续追加assistant与工具结果并用于下一请求。来源与恢复入口已有；这三个文件及必要激活装配中的缺口是选材不能排除默认记忆材料，同醒累积材料也缺少重选路径。此为静态范围内的发现，不是生产观察；不据此增加任务切换模块。

在合成材料上改变当前问题和线索，观察选材怎样变化；A → 无关B → 返回A可作明显案例，但不给实现提供任务状态机、固定边界或期望保留比例。检查实际主模型请求，确认前置选择能排除默认近期的大段无关材料，也能保留必要近期材料；追问进展、理由、实施和核验时仍可找到正确原件。再看局部依赖、渐变关注和长工具过程中重选的情况。

首轮记录实际入模材料、回源与错误关联、已有决定的恢复，以及选择／恢复的token和时间成本。假传输只能证明选择实际生效，不能证明模型选得好；“未引用”不等于错选，“后来查原件”不等于漏选。每醒重建和同醒内重选分开观察，不预设每条消息固定增加一次整理调用。再按实际瓶颈选择检索或编码机制，当前实验尚未执行。

## Claude思路补充后的修订

维护者补充自己的要求：编码器必须可演化，演化空间足够大，演化操作最好可交换且可规约。本轮核对的是设计前提，没有执行训练、嵌入调用或生产改动。

讨论曾提出L0／L1／L2三层、按目标完成切段等候选。维护者随后纠正了预先规定结构的做法；这些候选未被选定，不作为接手实现合同。可继续保留的是原件可定位、理解可修订、按问题取依据；不强制独立句柄层、固定要点字段、唯一日志区间或“只记意外”。

心理学原始来源：[Reyna理论综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4268540/)区分平行的gist/verbatim痕迹，不保证所有遗忘细节给线索就能恢复；[Masicampo、Baumeister原文](https://users.wfu.edu/masicaej/MasicampoBaumeister2011JPSP.pdf)报告具体执行计划可缓解所测未完成目标干扰。因此“未完成一律常驻”不是研究推出的规则。人类组块数量也不作为模型上下文容量。

### 编码器演化：必须分开的对象

- 证据记录及其稳定ID，是细节定位的依据。
- 编码器参数theta_v及Encode_theta，是可改变的解释／检索方式。
- 对模型的演化操作U，是作用于编码器状态的函数。记录合并可交换，不自动证明U之间可交换。

已核对的数学修正：

1. “可交换等价于不依赖当前状态”错误。U_a(s)=a*s依赖状态，彼此仍交换；记录计数与均值的在线更新也可以依赖当前状态且最终次序无关。固定似然下的贝叶斯证据累积提供更有意义的实例。“状态无关”也不能单独作为充分条件：状态无关的加性增量可交换，分别覆盖为两个常量则不交换。按当前误差决定是否接纳、如何加权，可能使最终接纳的证据集合本身不同，不能只靠后续合并交换消除该差异。
2. “高维近正交所以演化近似交换”缺少条件。对A(x,y)=(x+y,y)、B(x,y)=(x,x+y)，在(1,1)增量为正交的(1,0)、(0,1)，但A(B(s))=(3,2)，B(A(s))=(2,3)。补零到16384维，差异不变。梯度更新的交换子还依赖Hessian如何作用于另一梯度，不由梯度夹角独自决定。
3. 交换／结合保证重排／分组，不自动给出紧凑、有效可计算的唯一规范形，也不证明模型语义等价可判定。数学向量加法的性质不等于float16任意累计顺序逐bit一致。
4. 可逆是额外要求，并非纠错的前提。交换幺半群若每个元素有逆则成为阿贝尔群；但任意丢失信息的摘要不能补一个逆恢复细节。减去某贡献也不自动撤销由它产生的后续推断；可保留原件并从有效证据重算。
5. 固定哈希码本可再生且利于寻址，但无限新增名字不等于有限维表示具有无限无干扰容量，也不自动获得语义泛化。

最小候选模型：E按稳定ID合并，theta_v=Fit_v(E)，z_v=Encode_theta_v(x)。把Fit定义为集合函数时，同一批带时间／来源的证据应得到同一结果；实现收到完整E本身并不证明这一性质。要求逐次复现，还需控制版本、配置、外部依赖、随机性及并列解；可规范输入顺序或使用排列不敏感的算法。仅固定随机种子不足以排除输入顺序改变随机数分配。到达顺序无关也不等于抹去事件发生时间。

此性质属于证据接纳／重建结果，不冒充任意在线编码器修改可交换。计算代价可能是全量重算；不存在已证实能支持任意未来编码器的小统计量。固定特征下的岭回归可累加X^T X和X^T y，换特征通常仍需原记录。

若进一步要求编码器修改本身交换，需显式选择并验证操作族；共享坐标下的某些加性参数、固定基底的对角缩放可以，换目标、换特征或架构不自动可以。稳定经历ID负责回源，向量索引属于特定encoder版本；旧向量仍可在旧空间使用，跨空间混检需要兼容验证或重编码。

### 原始计算机文献核对

- [Shapiro等，CRDT原论文](https://www.cs.tufts.edu/~nr/cs257/archive/marc-shapiro/CRDTs-beatcs-2011-06.pdf)：state-based的半格merge满足交换／结合／幂等并要求相应传播；op-based约束并发操作及投递条件，不要求所有操作幂等。不能把数据最终收敛当学习质量保证。
- [HyperLogLog原论文](https://cermics.enpc.fr/~meuniefr/FlFuGaMe07.pdf)：相容配置按寄存器max合并，不是估计值相加。
- [Frequent Directions原论文§3.1](https://arxiv.org/html/1501.01711#S3.SS1)：合并经草图拼接再规约并保留空间／误差保证，不保证与顺序运行的草图矩阵逐元素一致。
- [Plate，1995](https://redwood.berkeley.edu/wp-content/uploads/2020/08/Plate-HRR-IEEE-TransNN.pdf)、[Kanerva，2009](https://www.rctn.org/pkanerva/papers/kanerva09-hyperdimensional.pdf)：随机独立、各向同性单位码的叠加估算，不可直接移植普通语义embedding。sqrt(D/k)为相对单个干扰标准差的分离量，不是检索成功率；码本大小、相关性和清理检索都影响结果。

本轮用无文件的小型算术核对了缩放更新交换、上述正交反例，以及固定高斯似然两观测按相反顺序得到同一精度／自然参数；不是大维模型实验。后续值得验证的切片为：同批合成经历打乱／分块／重复接纳；充分统计学习到不同参数且次序无关；新关系要求换特征后从原件重编码；最终在相同上下文预算下比较理由／细节找回、错误关联与重编码代价。尚未选择实现方案或执行这些实验。

## 后续讨论：有损整理、主体状态与实验边界

2026-10-22维护者转来Claude修正与三点补充。本节吸收可支持的部分，保留限定；转贴中的“维护者优先、再按时间”是示例，没有成为维护者裁定的冲突规则。

**有损规约会引入新的路径依赖。** 若模型按当时理解决定丢弃哪些材料，随后只在压缩结果上学习，即使后续合并可交换，不同历史也可能留下不同E。保留可定位原件，使派生摘要／检索索引能够重建，但不承诺重算廉价，也不要求原件全部进入上下文。

**随机性与路径依赖要分开。** LLM整理可建模为随机映射K_v(E, ·)，不能因非确定就说它无法建模为函数或分布。顺序无关可以要求输出分布相同，不必要求每次文本相同；确定性增量学习也可能依赖顺序。当前增量图书管理员不承诺字面复现或顺序无关，实际程度仍待测量，不能预先把全部差异归因于路径。

**并非所有笔记都是可丢弃视图。** 派生摘要和索引可以重建；主体亲自采纳的判断、偏好、承诺及其修订，本身是经历的一部分。按已保存的决定恢复状态，与让新模型从旧材料重新作决定，语义不同。此区分延续[D18](decisions/D18-确定统一事件与文件记忆的首版职责边界.md)允许主循环记下自身理解、共同保留来源与版本的选择，不新增笔记分类系统或写入角色。她仍可修订自己的理解，历史记录帮助说明何时、因何改变。

**合并记录不等于裁定更正。** 相互冲突的更正可同时进入记录集合；何者取代何者，要看明确的修订关系、证据和各方对具体问题的决定权。时间较晚不自动更真；维护者对偏好或权限的裁定也不自动证明外部事实。现有父版本校验防止陈旧覆盖，不判定自然语言真假。未裁定的冲突保留，不在本次讨论中选定通用胜出规则。

后续若实际查找或演化瓶颈需要比较检索方式，可用关键词、现成嵌入接口、哈希码本超维向量三种候选基线；不是先于任务切换实验的必跑清单。同一材料、问题、过滤语义和上下文预算下比较相关经历找回、错误关联、正确原件取回及重编码成本。哈希码本需明确使用的实体／关系／别名输入；人工额外标注和接口调用成本一并计入，不能只比较向量计算。演化检验还应加入旧特征无法表达的新关系，避免只测出静态寻址能力。现成接口仍只是实验候选，本轮没有调用。

| 受控变化 | 检查的问题 | 解释边界 |
| --- | --- | --- |
| 完全相同输入与配置重复运行 | 运行间波动、可复现性 | 差异不直接证明顺序依赖 |
| 同一E改变到达顺序，保留事件时间与内容 | 接纳／学习的到达路径依赖 | 先规范排序只能检查该重建路径，不能替增量整理背书 |
| 同一E改变处理分块与合并顺序 | 局部整理、压缩与合并带来的差异 | 排列检查通过不代表分块检查通过 |

确定性实现按事先声明的精确值或数值容差比较；LLM整理先测同输入波动，再比较事实保留、错误关联、来源与决定是否被改写，避免仅按文本是否相同判失败。区分这些变量后，才有依据判断差异来自随机性、处理顺序还是有损规约。以上是待执行实验设计，没有新增实测成绩。
