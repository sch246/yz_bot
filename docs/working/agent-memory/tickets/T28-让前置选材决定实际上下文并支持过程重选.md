## 最小验证与可观察结果

- 默认recent含大量无关合成材料时，前置可以排除它们，也可以保留必要近期内容；以实际发出的请求为证。
- 改变当前问题和线索，观察选择随之变化。A → 无关B → 返回A、局部依赖与渐变关注都可作案例；实现不接收硬编码任务标签或期望重叠比例。
- 同醒工具产生长结果后，下一次选材能改变实际后续请求；必要结果／约束和合法工具配对仍在，明确取消与未知结果不会被摘要成完成。
- 追问进展、理由、实施或核验时能读到正确原件；缺失理由不补造，原有决定可恢复并可由主体明确修订。
- 记录实际入模材料、错误关联、回源结果、token／耗时。未引用材料不直接判错选，后来查原件不直接判漏选；结合当时可知信息解释。假模型验证接线，真实模型效果须另有实际证据。
