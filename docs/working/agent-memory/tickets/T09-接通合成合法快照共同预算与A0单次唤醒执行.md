## 最小接口与输入契约

拟议普通函数：`run_synthetic_wake(frozen_sources, schedule, cursor, wake, budget_fixture, output, *, scenario="normal") -> report`。函数名可调整，以下语义固定。

- `wake` 含独立 wake_id、已开放 source_alias、可见 event_key 和原因。引用未来或其它来源必须拒绝；一次调用只接受一次外部唤醒。
- 预算复用 T08 的 request_rows/lineage/budget_policy 契约：新运行、默认 synthetic Ledger 政策、固定归属。每个实际 request_id 关联 role_id/task_id/run_id/branch_id/parent_checkpoint_id/stage/snapshot_id。
- 最终 HTTP hook 重新读取完整 Ledger 切面，调用 project_costs/admit_request，在同一串行临界段完成原 Ledger 持久预留。准入结果不能缓存后另行发送。
- 原 envelope 与归属记录是投影事实；原 Ledger 是费用/预留唯一权威，不增加第二份可写余额。归属或请求证据持久化失败必须在 mock 前闭锁。
- 一次运行只允许原 A0 读取、正式阅读及内部记忆操作；say 明确拒绝，没有候选回声。这是本票切片限制，不是对完整 A0 能力公平性的改判。
- CLI 仅接受内建合成 fixture/scenario 与新的输出根；没有凭据、真实材料、真实 endpoint、任意 transport 注入或付费模式。

## 报告与验收证据

报告记录 manifest/schema/code/source/schedule hashes、snapshot_id/wake_id、实际请求/预留/结算/工具顺序、正式输入数、共同预算 S+I+R 及拒绝原因、停止状态、绑定恢复及哨兵覆盖范围。合成 wire body 留在仓库外证据目录；含未开放 bytes 的快照控制对象不得进入模型输入。

1. 正常路径实际经过 SDK、parser、A0 take/read_messages；下一份最终 HTTP body 包含正式读入内容和配对工具结果。来源原文对应 T07 映射。
2. 两群同秒/同 ID 可区分；未来窗口、目录、名字和原文独特标记均不进入工具结果或实际 wire body；多轮工具/请求不推进开放游标或虚拟时间。
3. 共同限额先于本地 Ledger 限额耗尽时，下一请求被拒绝，mock/工具新增次数为零；共同 S+I+R 与实际 envelope 预留量一致。
4. 缺/冲突/超报 usage、连接失败、length、reserve/settle 持久化失败、生成器取消均闭锁；结算成功前工具数为零，不能换 role/branch 绕过终止。
5. 外部可丢弃验证脚本能检出至少一个跳过共同准入或混入未来标记的故意错误，不能只相信新函数自身报告。
6. 原 bind_a0_view 仍拒绝模型和动作；正常与异常退出恢复 cwd、TZ、模块绑定和 context.current。生产访问、非输出根写入、socket、QQ 哨兵在声明覆盖范围内为零。
7. 交 commit SHA、实际命令/exit/hash、失败反例和覆盖限制。显式编译新增源；Python check 与同机 smoke 前后比较。重 CPU 验证优先在 4 号机现有隔离环境进行，只传 allowlist 代码与合成材料。不引入永久测试框架。
