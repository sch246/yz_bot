# 主体持续性：当前理解与首个原型

日期：2026-10-20。对应 [D17](decisions/D17-重审主体持续性与自主选择的目标和实现方向.md)。这是主代理整合后的研究结论和原型建议，不是已经实现的能力，也不把“自我”的本质问题宣布解决。本次没有运行模型、读取生产材料或凭据、修改生产代码。

同日新增[Hindsight、Cortico 与 meow-memory 补证](agent-memory-reference-update-20261020.md)，核对已有的知识修订、持续循环、自定再醒及原代理整理机制。它补强以下路线的复用依据；各项目的论文、设计主张和固定版本实现分别记录，不把同名 reflect／dream 当作相同机制。

## 目标与当前工程判断

维护者说：“我想要的是一个有自我的主体，而不是一个上下文总结机器”；至于无人交任务时做什么，回答是“让她自己决定”。[基础讨论一至三节](../proposals/memory-foundations-discussion.md)已经明确：目标是具身、持续积累经验的通用 agent，结构是她本身，上下文是结构上的切片；不能用少数成功场景替代全部期望。

据此，本轮的工程判断是：先让运行中的系统形成自己的取舍，使这些取舍留下可被以后使用、也可被新经历修正的实际影响。先前的经历既可以影响说什么，也可以影响现在关心什么、读什么、继续哪条线、是否暂时不做。这里说的“自己的”是待检验的系统属性，不能靠一句角色提示、模型自称或给文件起名来成立。

主体指这个持续运转、与环境耦合的整体，不能只指中心模型的一次调用。前置选材、整理和以后可能出现的其它求值过程都可能是它的内部过程。单靠“中心模型审批了”也不能证明某次改变属于她；要追踪改变怎样从这个系统此前的经历产生、怎样参与后续选择、又怎样接受新经历的纠正。

这不要求她永远维持同一兴趣，也不要求每次都修订自己。继续、改变、搁置、静默都应当有空间。初始模型、提示、环境和工具当然含有设计者的先验；需要如实记录这些先验，不能用“没有预写逐步动作”冒充目的完全不受外界影响。

以下是代码与合成校准事实，不是对生产中柚子行为的观察。

生产源码也已有可以复用的接点：中心自写 `edit_hint`、不调用 `say` 而静默结束、显式选择发言窗口、持久定时执行。静态出处分别为 [meta.py](../../../mods/tools/meta.py) 的 `edit_hint`、`say`，[聊天入口](../../../mods/chat/__init__.py) 的 `set_agent_hint` 与提示注册，[later.py](../../../mods/later.py) 的 `_action`、`_schedule`、`run`。但 `later` 本身执行代码，不会自动唤醒中心模型；这里没有运行验证，也没有查看现有 hint、权限或定时任务。

## 外部工作能借什么

[Generative Agents 原论文 §3–4](https://arxiv.org/html/2304.03442v2)把经历、计划和反思重新用于计划与反应；这支持借鉴“过去参与下一步，并可因新观察重规划”的机制。但身份与若干起始意图由作者植入，端到端观察只有两个游戏日；论文明确限定其行为可信度目标，不据此宣称真正的自主主体。它没有替我们回答柚子该在意什么。

[Voyager 原论文 §2–3](https://arxiv.org/html/2305.16291v2)根据环境、能力与成功失败经历选择后续任务，将执行反馈用于修改代码并积累技能。这支持借鉴“实际能力和结果改变未来选择”。但[作者的 curriculum 提示](https://github.com/MineDojo/Voyager/blob/main/voyager/prompts/curriculum.txt)预设探索方向及任务限制，不能把在此外定方向内选任务等同于自行选择生活方向。

两者提供局部机制与边界，不能充当“主体性已解决”的证明。本项目还应复用[同相上下文中的反馈研究](../proposals/self-maintaining-context.md)：自我描述会反过来塑造未来，原始轨迹只是实际发生的一条路，文本被使用也不自动证明应给它全部因果信用。

## 要接通的循环

```text
先前经历、既有结构与当前可见环境
  → 本次形成理解与取舍
  → 实际行动、静默，或留下可重访的改变
  → 环境产生结果／以后取得新观察
  → 后续求值真正使用此前的改变和新结果
  → 继续、修订或放下，再进入下一次选择
```

箭头不能全由实验脚本替她填写。尤其要区分“观察到的世界事实”“当时自己的理解或倾向”“执行后的实际结果”：她可以修订理解，不能靠改笔记改写已经发生的外部事实；尚未取得反馈，也不能写成成功或失败。来源和修订历史可以共用现成机制，不因此要求另建三套存储。

内部过程可以提出有意义的改变；是否采用、何时生效及以后如何撤回必须在这个系统的实际求值中成立。不能让一个固定后台整理模板不经检验地把推测写成她的永久立场，也不能为此新增一个无所不知的总审批器。先用最少的现成机制接通，再根据失败决定是否拆分职责。

| 部分 | 复用 | 需要改变的关注点 |
|---|---|---|
| 当前求值／聊天 | T10 的每醒输入、原文访问、结果与终态 | 从固定完成任务的脚本，转为能形成继续、改变、搁置或静默的实际选择 |
| 前置选材 | T11 的范围过滤、来源绑定与实际消费 | 不只围绕最新来信检索；自身尚未放下的线索也能参与选材。选材不能替她永久规定关注点 |
| 持久修改／整理 | T12 的候选、版本、提交和回退思路 | 内容及采用理由来自运行过程；后续能重新解释或撤回。不能把版本链本身当成学习 |
| 驱动与结果 | 现成事件、时钟、结果记录和预算边界 | 给出无新来信时继续求值的机会，允许她选择模拟重访；不把固定时钟频率或主动发言数当自主性的尺度 |

三角色仍是可实验的职责分配，不是主体目标本身。当前没有证据要求取消它，也没有证据要求每轮强制按三段执行；辅助过程是否单独调用、何时运行，应由实际摩擦与成本决定。先不新增人格档案、欲望管理器、固定奖励、向量库或可训练编码器；不是排除这些方向，而是尚未得到需要它们的证据。

## 首个可逆原型建议

下一步适合用 `prototype` 验证上述循环，不回到旧新记忆收益对照。原型隔离于生产，全部用合成环境和假外部动作；真正让模型形成选择的运行，与不调用模型的机械校准分别报告。本文只准备范围，尚未实现或执行。

1. **提供身体和处境，不提供兴趣答案。** 输入交代可见环境、可用工具、成本与权限，以及明确标作合成的经历；不预写“她最喜欢A”、当天任务顺序或改主意的目标答案。记录初始提示和种子，避免把植入内容当成后来形成的选择。
2. **让内容在运行中产生。** 在可读材料与可改状态内，允许读取、留下改变、继续或静默结束、提出模拟重访。工具是能力边界，不是每轮必填步骤；不要求先编一份长期目标表才能行动。具体改变、理由及是否采用由实际求值形成。
3. **跨醒使用，再给出结果。** 下一次从实际提交的结构重建，不能由脚本改写成理想人格；记录哪些内容进入真实请求。模拟效果由独立环境状态转换产生，注明其人为规则；模型的自评不充当环境成功回执。随后允许保留、修订或放下，观察其与已有经历的关系。
4. **针对一个疑点作局部核查。** 例如暂不加载某次自产生的改变，或只改变与它有关的反馈，检查后续取舍是否相应变化。它只诊断当前候选的一条因果联系，不重建旧新四臂；保持其它条件、记录随机差异，证据不足时保留未知，不以单次回复差异证明因果。

原型应交付一条可复查的跨醒轨迹：当时可见什么、哪些选择由模型产生、哪里改变了持久结构、之后实际加载了什么、环境真正返回什么、以后怎样处理。可以先隔离复用 T10/T11 和 T12 的机制，不要求先修完三角色全部联调。

需要直接暴露的失败包括：改变只存在于日志而未被后续使用；后台悄悄改写了她的立场；脚本预设了下一步；没有新来信就永远没有继续的接点；观察、推测与执行结果混为一谈。反过来，静默、不改笔记或维持原选择本身不是失败；要核对当时是否真的具备选择条件，及其与经历的关系。

这一原型只能检验一段持续选择与修正机制，不能证明主观意识、通用自我、长期稳定性或完整的学会学习。兴趣为何形成、冻结模型先验占多大作用、何种结构能支持更长跨度、如何改善改进方法本身，仍待研究，不变成请维护者替她选兴趣的门槛。

## 对既有票据的接续影响

D17可以回答当前路线问题：主体按持续系统理解；先验证自产生的选择／改变如何被以后使用和经验修正，保留机械成果，三角色作为候选。这个研究答案不等于总体目标已经完成。

T12 的混合 role/note alias 返工仍需按原失败证据验证，不能因方向结论而宣称完成。T13 仍是草案；先把它原来的机械三角色联合范围与上述原型需要的语义选择、模拟重访和独立反馈作实际接口核对，再决定最小实现切片，不直接将原草案置为 ready。D10 的可靠性与 D12 的经验消费继续提供必要检查，但准确问答、次数和成本不再被当作主体性的充分验收。

本轮无需新的维护者选择：下一步的缺口是可运行证据。既有授权和生产边界保留；研究结论本身不增加数据、凭据、付费或生产操作范围。
