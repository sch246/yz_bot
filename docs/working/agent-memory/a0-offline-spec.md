# A0 合成离线校准实施范围

来源：[D05](decisions/D05-裁定首轮验收取舍-样本范围和预算.md)、[D09](decisions/D09-确定比较器可复用部分与最小离线补齐范围.md)。2026-10-19，维护者在确认“只实施最小 A0 离线适配与无模型校准”后答复“直接做吧”。此前规划与证据仍保留；本范围只放开实验代码及合成校准。

## 交付

在 experiments 中提供一个可复现的无模型入口，使用固定合成档案、虚构身份、脚本响应及明确的合成价表。复用真实 A0 reader/base prompt 与既有隔离/hash/lock/checkpoint机制；不实现 A1–A3、出题器、笔记机制或正式比较器，不改变 mods 生产代码。入口不能接收真实输入包、凭据或生产配置，也不构建真实模型客户端。

1. 同一隔离作用域内按固定前缀开放事件、至多三次外部唤醒；跨 drive 保留 reader/oplog/tool 状态。普通事件与候选回声不创造额外唤醒。全部 A0 暴露读取路径、名字、目录和虚拟时钟只见已开放过去。say 写分支回声，后续可反查且原文定位保持一致；context.current 不触发生产收尾求值/发送，finally 恢复绑定。
2. 同一 pilot/request 标识管理单个在途请求与持久总账。默认上限三唤醒、十二尝试、每次输出4096、allowance 合计49152、费用5元；输入上下文限额和价格必须显式冻结。完整请求保守预留，缓存计一次，金额向上取整；缺价或未知额外费拒绝，缺 usage 按全额预留，超报记实际并闭锁。合成价表只校验算法，不能作为真实报价。
3. 请求失败不重试、不回退、不追加收尾请求。通过 fake transport 注入失败核对实际尝试数；这只证明实验入口，不证明现有生产 SDK 的行为。取消、length、流断、持久化失败或未知结果都保留停止证据，不伪造已完成或可恢复 checkpoint。
4. manifest 冻结合成输入/时序、代码/base prompt/schema、模型标签、计价与限额；同一 root 锁、累计账本不重置。漂移、损坏、在途未知状态和并发启动拒绝。恢复只支持已经完整校验且 settled 的状态；尚未支持的恢复边界必须明确拒绝，不借用旧 checkpoint 宣称已支持。

## 验收

实际执行合成场景，提供分项断言与失败结果：三唤醒/合法过去/读取路径/回声不唤醒/状态与绑定恢复；第十三次与输出限额；恰好和超过费用边界、缓存、缺价/缺 usage/额外费、usage 超报；失败/length/取消/持久化异常闭锁；manifest 漂移/账本损坏/并发锁及声明的恢复边界。真实网络/模型/QQ/生产路径写入为零，fake 尝试另计。

保留旧 doctor 回归；执行仓库要求的 Python check、临时运行根 smoke 并对比基线。不要新增常规测试套件；必要的探针置于仓库外，合成 doctor 可作为实验入口功能。文档运行 diff --check 与相对链接验证。

## 停点与接续

完成本范围不等于 D05/D10 解决，也不证明记忆收益、真实费用或真实供应商兼容。真实三天材料、七天留出、配置与历史模型输出仍不得读取；真实调用和5元支出仍未授权。下一步按合成结果指出真实小试前尚缺哪些事实，不重复询问已经裁定的方向。
