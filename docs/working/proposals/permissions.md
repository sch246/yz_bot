# 权限演进

> 状态：未实现提案

权限系统遵循 KISS，不演变成复杂角色与策略语言：

1. 每个命令声明整数级别；
2. 调用者提供可比较级别；它由现有 master/op 推导还是单独配置，尚未决定；
3. 少数命令可附加一个正则或普通函数校验器；
4. 校验器针对具体消息额外允许或拒绝。

整数级别覆盖绝大多数权限，额外校验只处理上下文例外。实现前必须用少量例子定死“显式拒绝是否覆盖级别允许”“校验异常如何处理”等优先规则。

历史上 0.2.1 命令 class 已有 `level` 字段；当前函数插件没有统一执行检查。迁移时应提供简单 wrapper/函数，不把参数解析、角色继承和资源策略塞进 cmds 核心。
