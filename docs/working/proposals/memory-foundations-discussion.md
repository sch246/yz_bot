## 〇、起点：试验品的实际失败

> 我实际运行时这个记忆很难用，ai 总是忘记刚刚发生了什么，把握不住时间顺序。

当时只读了代码和已有回放记录，没有检查生产 oplog 与日志，因此下面各项**都可能造成**这个症状，但哪一项是主因还没有核实。

**时间感缺失。**

- 模型看到的上下文里没有当前时间。
- 只有外部消息投影带 `<time>`（`mods/chat/view.py` 的 `msg2chat`）。模型自己的输出、工具返回和原生 assistant 消息不带时间，尽管每条 oplog 记录都写了 `read_at`。
- 通知与尾部未读提示里的时间是原始 Unix 秒（`_activation_text`、`_unread_detail_text`、`reader._pending_hint`）。

**顺序是阅读顺序，不是发生顺序。**

- 正式号在读取时分配，先读的群、后读的群、回翻的旧档案按读取先后排进同一条流。
- `cover_events` 的结论挂在发起覆盖的那次输出的位置上，于是较早材料的总结会出现在较晚的原文之后。

**“刚刚发生的事”可能根本没被读入。**

- 唤醒通知不带正文。
- `take(source)` 默认从最早的未读开始取 8 条。
- `mentions` 只读提及本身，不读前后文。

**刚读的内容容易被立即折叠。** 回放记录显示，模型习惯读一页就覆盖一页，而代码中没有保护最近经历的机制。

[长期记忆离线回放实验](memory-replay-evaluation.md)此前已测到的相关失败：

- 默认提示不会递归整理，叶摘要随阅读页数线性增长：读到 1,344 / 8,716 条时，prompt 已达约 127k token。
- 覆盖结论没有语义下一跳，反查变成大范围枚举（12 次行动中只有 3 次落在正确祖先链）；要求内联引用直接成员号后，路径收敛，但形成成本约翻倍。
- 整理与聊天共用同一上下文，长思考经常因 `length` 截断。

当时据此提出过一组修补：补时间戳、唤醒时自动读最新消息、滑窗替代固定起点、`search_events`、可改写笔记。这些修补**没有被采纳为方向**，原因见下一节。它们仍可作为以后验证某个假设时的候选手段。

## 一、停止修补，先问问题

> 我想要讨论更根本的问题，这只是一个试验品。在明确问题之前任何的推进都可能是无用的。
>
> 我想要的是一个具身的 agent，可以持续积累经验的通用 agent。
>
> 什么是记忆系统？我们想要的是什么？我们面临的是什么问题？

修正：前三轮把“当前系统难用”当成待修的缺陷，默认了它的目标是对的。这里退回到目标本身：现有 oplog／cover／recall 只是一次实验，不预设它是正确的基础。

## 二、记忆是过去影响现在的方式

### 功能定义

记忆是**过去经历影响现在行为的方式**。存储量不是判据，重要的是过去能否改变现在，而且是有用地改变。

对权重冻结的 LLM agent，过去影响现在只有三条通道：

1. **权重**：主模型的权重改不了。
2. **这一次调用的上下文**：唯一的“当下状态”，每次调用后消失，下次重建。
3. **世界里留下的痕迹**：文件、笔记、代码、工具、link，以及别人记得的东西，agent 之后会重新感知它们。

因此，对柚子而言，“记忆系统”包含两件事：**重建策略**（每次醒来把过去的哪些部分放进本次上下文）和**外化**（在世界里留下什么，好让以后的自己看到）。

> 后来修正：第 1 条通道只对主 LLM 关闭。小型选择／嵌入模型可以在柚子自身的经历上训练，权重通道并没有完全关闭，见[第四节](#四用预测统一写入与读取)。

讨论中用过的类比是《记忆碎片》里的 Leonard：无法形成新的长期记忆，靠纹身、照片和便条生活。每次调用都是一个刚醒来的 Leonard，失败方式也相同：不知道刚才发生了什么，相信一张过期的便条，分不清先后。

### 具身

柚子的身体是 QQ 窗口（感官与发声器官）、宿主机和它自己的代码。它能改自己的身体：写一个工具、加一条 link、改一个 Skill，都是把经验写进身体。这是最持久、也最容易检验的经验形式，因为工具要么能用，要么不能用。经验不一定以“回忆”的形式存在，也可以以“环境已经被改成适合我的样子”的形式存在。

旁证：`mods/watchdog.py` 是在聊天中与维护者共同做出的身体改动；[柚子手记](../kouzi-memo.md)是柚子在 oplog 覆盖图之外自己写的、按“人／进行中的线／主题／约定／待归类”组织的备忘。这两次成功的积累都走第三条通道，没有经过覆盖图。

### 想要什么：五种不同的东西

草籽认为这一划分有价值。

| | 是什么 | 时间尺度 | 当时的状态 |
|---|---|---|---|
| 连续感 | 知道刚才发生了什么、现在在做什么 | 分钟到小时 | 失败 |
| 对世界的了解 | 人、关系、事实，以及它们怎样变化 | 天到年 | 基本只有系统外的手记 |
| 技能 | 会做某件事、少犯同样的错 | 跨任务 | 部分成功（工具、Skill） |
| 自我 | 我是谁、答应过什么、在乎什么 | 长期 | 几乎只靠 prompt |
| 学会学习 | 上面这些过程本身变好 | 最长 | 只有理论讨论 |

当时的判断是：现有设计试图用同一个结构、由同一个正在聊天的模型、在聊天过程中同时承担前几种，这是它难用的根本原因。

### 当时列出的问题

1. **核心约束是重建，不是存储。** 权重冻结、单次上下文有限、经历无限增长，因此连续性只能每次重建；问题是重建的质量能否随经历增长而变好，而不是变差。草籽的表述：“核心约束确实是过去的结构如何影响现在的行动。”
2. **维护与行动争夺同一份注意力。** 整理和聊天共用一个上下文、一次推理。（这里当时提出的“离线巩固”在[第三节](#三压缩即理解与主从反转)被解构。）
3. **写时不知未来用途，读时不知已有内容。**
4. **没有学习信号。** “玻璃盒 RNN”让状态转移规则变得**可修改**，却没有回答**按什么、往哪个方向修改**。RNN 有梯度，这里唯一的优化器是 LLM 自己，而它得不到“上次改动变好还是变坏”的信号。同相性让自我修改成为可能，但不让它有方向。
5. **模型能力是硬上限。** 依赖模型在线做复杂自我整理的设计，会被当前模型卡死。

## 三、压缩即理解与主从反转

> 关于“连续的我”的问题，我想我们可以看看我关于中文屋的想法：穷举未来是不现实的，必然产生压缩，以进行输入输出的转换，你可以认为执行器没有理解，但是对于整个系统，这里的压缩本身就是理解。
>
> 对于上下文本身也是这样的，上下文本身是只活在此刻，使用纯追加的列表作为上下文，追加列表的上下文本身具有短期记忆和智能，可以被看作一个“意识”，但上下文和带记忆的驱动程序是另一回事，在记忆驱动下，主从反转了，结构才是它本身，而上下文只是在结构这个庞然大物上游走的切片，只是可以编辑结构和反应本身的焦点，单线程的追加列表只是一种常用形式，这完全是一种特例，即使是为了复用缓存，亦可以有无数的起点。
>
> 外界消息触发作为驱动是常见的，但未必是基础的，这直接解构了离线巩固的概念。我认为离线巩固应当是允许的，但是刻意去做则是容易偏离的。

由此确立的几点：

- **压缩即理解，且只在系统层面成立。** 执行器（LLM）可以不理解；把不可穷举的输入输出映射压缩成结构，这个结构就是理解。按香农的观点，压缩与预测是同一件事，这条原则也为第四节提供了判据。
- **主从反转。** 结构是 agent 本身；上下文是结构上的切片，是能编辑结构与反应的焦点。可以同时存在多个切片、多个起点。
- **对照现有试验品：** 它恰好建在特例上，把单线程追加列表当成了“我”，结构（cover 图）只是上下文活动的副产品。
- **驱动不止外界消息**，“在线／离线”的划分因此不成立。离线巩固可以发生，但刻意安排的巩固容易偏离（第四节给出一个解释：没有需要预测的当下，就没有误差信号）。

关于收集“成功例子”：

> 第一个问题我能给出一些例子，但是我认为这并不能代表我的期望，而如果视这少数的例子为方向，毫无疑问会带偏和狭窄化我的目的。

修正：此前提议用 3–5 个具体场景定义成功，这一提议被否定。少数例子会把通用目标收窄成这几个场景。第四节的预测判据不依赖任务和例子，部分回应了这一担忧。

关于按哪一档模型设计：

> 我认为现在已经临近边际效应了，甚至 jev 这种纯选择模型也在考虑范围。

当时把“jev”理解为 JEPA 一类在表示空间中预测、不生成文本的模型，这一理解**尚未得到确认**。含义是：生成式大模型的能力已经不是主要瓶颈，结构与选择机制才是。

## 四、用预测统一写入与读取

> 写和读的问题我认为得参考人类……核心判据可能还是用预测统一写入和读取，但是如何统一，关键在哪里是个问题。
>
> 学习信号本质面临的是同一个问题。

### 读即写

人类提供的线索：

- 海马体编码依赖预测误差：出乎意料的东西才被记住；
- 回忆是用当下线索补全一个模式，补全本身就是一次预测；
- **再巩固**：被取出的记忆会进入可修改状态，按当下的预测误差重写后再存回。

所以没有分开的“写入”与“读取”：结构在**被使用时**，按它对当下预测得准不准而被改写。这化解了“写时不知未来用途”：写入时不必知道，先低成本留下原始痕迹，结构形状由之后的使用和误差慢慢塑造。

| | 用预测表述 |
|---|---|
| 读 | 选出最能帮助预测当下的那部分结构，放进切片 |
| 写 | 结构片段在被使用时按预测误差被加强、修改或衰减 |
| 学习信号 | 结构对**实际随后发生的事**预测得怎样 |

### 世界是无法篡改的判定者

[研究地图](memory-and-self-evolution-research.md)把“没有免费的判定者”列为第一条结构性约束。但在“预测世界”这一侧，判定者是免费的：接下来实际发生了什么，agent 无法改写。这也解释了刻意巩固为何偏离（没有误差信号，只能对着想象中的未来优化）。离线时依然可以有误差信号：用 t 之前的结构预测 t 之后实际发生的事，这与 LLM 预训练是同一原理。

[记忆估值与索引演进](memory-valuation-and-index-evolution.md)中的 Δ_mdl，即给定某个结构片段后后续经历编码长度的缩短量，在此框架下不再只是旁路观察仪器，而是写、读、学习三者共同判据的一个候选形式。

### 当时认为卡住的地方

1. **读的机制必须便宜，并且不靠刻意推理。** 人的回忆按内容寻址、并行、几乎不费力；agent 的读取是刻意、串行、昂贵的工具调用，还得先知道该问什么。工程关键可能是一个独立于主模型、便宜的**联想层**：持续根据当下从结构中提出候选，并按预测增益打分。纯选择模型适合这个位置，而且可以用同一判据在柚子自身的历史上训练，权重通道由此重新打开。
2. **长跨度信用分配。** 不可能拿每个片段去和整个未来比较。人脑依靠局部规则（使用时当场的预测误差、共同激活互相加强）。关键很可能是一条**局部的、使用时生效的更新规则**，当时说不出它是什么。
3. **预测世界不等于会行动**，以及无法从旧记录获得反事实。（第五节修正了前半句。）
4. **压缩总是相对于解码器。** MDL 需要固定的参照机器。结构是不是“理解”，取决于读它的模型；换主模型等于换了“我”被书写的语言。也许稳定的选择模型才应充当解码器。
5. **预测给出理解，不给出想要什么。**（第五节把它移到了“偏向从哪里来”。）

## 五、行动是对观测的补全

> 行动和预测是类似的，这可能回答了纯观察者问题和长跨度问题。
>
> 问题是：为什么要区分行动和观测？为什么要区分脑海的感受和外界观测？幼儿是分不清幻想和现实的，婴儿可能连行动和现实都分不清。
>
> 这就是为什么我要把事件都归入统一事件流。行动本质是对观测的补全，是选择，而不是单独的概念。

### 补强

- LLM 本身就是证据：序列中自己生成的 token 与输入 token 没有区别，生成就是预测下一个 token 并从中选择。
- 主动推断把这一点推广到一切行动：行动是让预测成真。一种是改变预测去适应世界，另一种是改变世界去符合预测。

### 两个难题怎样被回答

- **纯观察者问题消失。** 预测自身未来的系统，其预测本身就包含自己会做什么。“想要什么”变成“倾向于选择哪种补全”，问题移到“偏向从哪里来”，而偏向属于结构，结构就是 agent 本身。
- **长跨度问题获得一个具体机制：未兑现的预测。** 意图是对自己未来选择的预测；承诺是被他人观察到的自我预测；计划是一串尚未兑现的自我预测。工作记忆可理解为当前所有悬而未决的预测。学习发生在预测被兑现或落空的时刻，误差流回当初做出预测的那部分结构；长跨度信用就是让预测保持打开，直到被结算（前瞻记忆）。现有 `edit_hint` 保存“还没做完的事”，是这一机制无意中的雏形，只是没有与之后的结算连起来。
- **没走的路**也是预测，只是永远不被结算。这与[同相上下文提案](self-maintaining-context.md#经验既包含走过的路也包含没有走的路)中“经验包含没有走的路”一致。

### 区分会以什么形式重新出现

婴儿后来**学会了**区分，而学会的方式本身就是预测：有些事件能从“我的选择”出发被完美预测，有些不能。大脑会给运动指令发一份副本用于预测自身动作的感觉（efference copy），所以人无法挠自己痒。“自我”就是被压缩出来的这样一条规律：**哪些事件可以由我的选择预测。**

因此，统一事件流不应是不分来源的一锅汤。为了让区分能被学会，需要保留两件事：

1. **来源永不抹去。** 否则自己的猜测、总结和想象之后会被当作事实读回（来源监控失败，表现为虚构记忆和幻觉），而且会直接破坏学习信号：只有知道哪些事件确实来自世界，世界才能充当判定者；否则系统会用自己的想象验证自己的想象。
2. **向世界提交的点是明确的。** 想象可以无代价修改，发出去的消息撤不回。认知上行动可以与预测统一，但身体上存在不可逆的边界；在柚子身上，这个边界就是 `say`、`exec_code` 等效应器，也是宿主信任域的边界。

当时的结论：**事件不分种类，但来源永不抹去；认知上不区分行动与观测，但向世界提交的点必须明确。** 区分不作为基本类型存在，而作为从来源中学到的规律或身体的物理边界存在。

### 对照现有代码

oplog 的 `input`／`output`／`result`／`notification` 与 `read_by` 大多就是来源信息，作为数据是合适的。真正的割裂在**处理方式**：输入经未读集合与 `take`，输出走原生 assistant/tool 配对，结果暂存到下一请求，通知另走一条路径。统一事件流在数据层面已大致成立，在处理层面远未成立。

## 六、测量函数与无常穿透

### 把 LLM 当作黑盒

> 我有考虑过不依赖大型 llm 个人计算机能否训练……目前的结论是很难离开，但是可以考虑将 llm 视为黑盒本身，只要迭代成立，那么建立其专属结构也是可能的。

这里确定了分工：主 LLM 不被训练，也不必理解结构，它是通用的测量仪与变换器；迭代的对象是围绕它生长的专属结构。

### 误差的单位

第四节留下的问题是：预测误差“住在”结构的哪里，局部更新才有落脚点。草籽的回答：

> 回到这个单位问题上，我的答案是定义一系列可变的测量函数用于观测外界，而这些函数的输出值本身就是预测对象。

于是误差的单位既不是事件、话题，也不是切片，而是**测量函数的输出**。结构先决定“看什么”，再预测“看到的会是什么”。结构可以理解为：测量函数的集合，加上对它们输出的预测，加上建立在这些预测上的选择。

这与两条已有路线相近（作者、年份凭记忆补注，未核对原文）：

- **预测状态表示**（Predictive State Representations，Littman、Sutton、Singh，2001）：状态不是内部描述，而是对一组“测试”结果的预测；测试即“如果这样做，会观测到什么”。
- **Horde 与通用价值函数**（Sutton 等，2011）：知识被表示成许多小预测，每个预测回答一个关于可测信号的“问题”。Sutton 的短文《Verification, The Key to AI》主张 AI 只能可靠地维护自己能验证的知识。

本讨论比它们多出的一点是**测量函数本身可变**，这对应 Horde 留下的“发现”问题：问题由人给定，系统自己提出新问题的能力尚不存在。

在柚子身上，测量函数的候选来源包括一段 Python（某群过去一小时有多少人说话）、一条 link 的条件谓词、一次把 LLM 当黑盒的判断（这个人现在是否不高兴），以及对自身行动的测量（发出的话有没有被回应）。最后一种与第五节一致：测量函数不区分它测的是世界还是自己。

### 常应常静：无常能穿透多少

> 常应常静常清净矣
>
> 这来自于关于无常的认知——所谓七窍玲珑心和通透无挂碍，指让外界的无常/随机，能多大程度地穿透这个人而影响到其行动。
>
> 讲通透不方便，我举反例更明显：不管外界发生什么都固定一套方案行事，那就阻隔了全部的变化。
>
> 不管外界发生了什么都反射同样的行为，那么这个无常就几乎没有穿透任何环节，除了反射这个行为。
>
> 某个行为如何反应最终只和一个变量有关，那么这个行为上最终只和这一缕无常相关。

这条判据补上了纯预测判据缺失的一半。只以“预测得准”为目标，会遇到自由能原理常被批评的**暗室问题**：最小化意外的最好办法是待在什么都不发生的暗室里。测量函数可变时，这个问题更尖锐：把测量换成常数函数，误差立即为零，而这正是“固定一套方案行事”的反例。

| | 含义 | 单独追求它的失败方式 |
|---|---|---|
| 静 | 对测量输出预测得准，不被扰动 | 暗室、固定方案、反射 |
| 应 | 世界的变化能穿透到行动 | 被每一点噪声推着走 |
| 常应常静 | 该穿透的都穿透，其余的不扰动 | — |

信息瓶颈（Tishby）是一个形式参照：表示对“有关的未来”保持充分，对其余部分保持最小，“应”对应充分，“静”对应最小。几个反例可以量化为世界变化与行动之间共享的信息量：固定方案为零，反射只有触发的那一比特，只依赖一个变量则不超过该变量的信息量。

柚子身上两个极端都已存在：**link 就是反射**，条件命中即执行，只有那一缕无常穿透；中心 agent 什么都读，任何噪声都可能推动它。结构应处在两者之间。

一个未验证的推论：穿透度不需要外部判定者就能离线测量。从同一检查点出发，只扰动一处输入，观察行动是否变化、变化多大。真实聊天给不出“如果我当时说了别的会怎样”，但“如果世界当时不同，我会不会做出不同选择”可以重放。

### 读即写的细化

有了测量函数，第四节的“读即写”可以写成三条局部规则（讨论中的提议，尚未确认）：

1. 某个测量的预测落空，局部修正它的预测器；
2. 残差无法被任何现有测量解释，生长出新的测量函数；
3. 测量长期不变化，或变化了也从不穿透到行动，让这个通道安静下来。遗忘因此是**关闭通道**，不是删除数据。

## 七、盲区与输入的充分性

### 盲区是器官层面的界限

误差只会出现在已有测量函数的输出上。世界若以任何测量都覆盖不到的方式变化，就不会产生误差，系统完全看不见。这种失败是沉默的，比预测错误更危险。

> 对……盲区问题是致命的，对应人类的器官。
>
> 这本质是一个哲学问题，人类无法感知自己不存在器官对应的世界。

讨论中提出过三种“开新通道”的来源：残差兜底（保留一个几乎不压缩的原始测量，比如 LLM 对原始下一事件的条件 logprob，现有测量解释不了而它显示意外的部分就是候选）、行动的失败、他人的纠正（借用别人的测量函数）。但它们都只能发现与现有通道有所接触的变化。完全没有接触的那部分世界，按定义无法从内部发现。这是需要接受的界限，不是可以在系统内部解决的问题。

### 全息与充分性

> 全息原理缓解了这一点，如同盲人也能认知世界，但输入依旧需要有一定程度的充分。我不知道我们目前是否有关于这种充分程度的测量标准。

讨论中给出的对应（未核对原文）：

- **Takens 嵌入定理**（1981）：对确定性动力系统，单一标量观测的足够长延迟序列，在一般条件下就能重建系统状态（相差一个微分同胚）。这是“盲人也能认知世界”的形式版本：**时间可以补偿通道的狭窄，而保存时间的正是记忆**。记忆与感官因此是同一种资源的两面。它的前提也正是边界：确定性、噪声小、状态维数有限且已知上界、足够长的历史。
- 其它关于“充分”的已有概念：控制论的**可观测性**（能否从输出重建状态）、统计学的**充分统计量**、PSR 的**核心测试集**（其预测足以推出其它一切测试的预测）、前述信息瓶颈。

没有一个能在开放世界里绝对地测量充分性，因为它们都要求事先知道状态空间或真实分布。实际能做的大概只是**相对充分性**：加入一个新通道后，其它通道的预测是否改善；若不改善，现有集合相对于它能看到的世界是充分的。绝对充分性无法从内部测量，这与上面的哲学界限一致。

### 记忆是一种器官

> 有意思，记忆看起来是一种器官。

这是由上面推出的工作推论，不是结论：

- **它感知的是过去。** 眼睛把光变成信号，记忆把时间变成维度。Takens 定理中的延迟坐标就是这样一个器官：用同一通道在不同时刻的读数，补出这个通道本身没有的维度。
- **它也有盲区。** 记忆只能感知当初留下了痕迹的那部分过去，而留不留痕迹取决于当时有哪些测量函数。盲区不因为有了记忆而消失，而是延伸到时间维度：当初没看的，以后也想不起来。
- **它是长出来的。** 器官是发育出来的，不是装上去的。这与下文“测量函数的集合是个体性的、长出来的”是同一个意思。按这个推论，现有 oplog／cover 结构用起来别扭，部分原因是它是由人预先设计、装上去的器官，而不是从柚子自己的使用中长出来的。

### 输出类型

> 测量的输出是一个数（浮点，整数，bool）可能是合适的，但目前也没有证据表明哪种更好。

讨论中提到的考虑：bool 最便宜、最易组合和验证；浮点能给出有程度的误差；若输出是文本，误差还需要再经过一次测量，可能形成无穷后退，也可能恰好构成层级（上一层的输出是下一层的测量对象）。哪种更好没有证据，保持开放。

### 测量函数从哪里来

> 如何得到这个测量我目前没有定论，但是费曼注意到每个人有自己发展出各种不同的思考方式，这似乎意味着这是一种天赋，或者是可发展的能力。

费曼在《你干吗在乎别人怎么想》（*What Do You Care What Other People Think?*）中讲过：他和 John Tukey 都能在心里计时，但费曼计数时能读书、不能说话，Tukey 则相反，因为一个是“听着”数，一个是“看着”数（此处凭记忆转述）。同样的任务，每个人发展出不同的内部测量方式。

推论：测量函数的集合是个体性的，是长出来的而不是设计出来的；产生测量函数的能力属于第二节的“学会学习”一行。讨论中曾提议由黑盒 LLM 根据残差提出候选，再由穿透度与预测增益决定是否保留，草籽没有确认这一提议。

## 九、当前工作假设

> 只有一种事件流。行动、观测和内心活动都是事件，区别只在来源，而来源永远保留。结构是 agent 本身，上下文是在结构上游走、能编辑结构的切片，可以有多个起点，由外界消息以外的事件同样驱动。主 LLM 作为黑盒的测量仪与变换器，结构围绕它迭代生长。预测误差的单位是一组可变测量函数的数值输出：结构决定看什么，再预测看到什么。写、读与学习统一为预测的形成、使用和结算：结构在被使用时按预测误差被改写（读即写），实际随后发生的事是无法篡改的判定者。判据不只是预测得准（静），还包括世界的无常能多大程度穿透到行动（应）；只求其一会落入暗室或噪声驱动。意图、承诺、计划是未兑现的预测，工作记忆就是当前所有悬而未决的预测。“自我与世界的区分”不是预设类型，而是从“哪些事件可以由我的选择预测”中学到的规律。唯一硬性的边界是向世界提交的不可逆点。完全不与任何测量接触的世界无法从内部发现，这是接受的界限；时间与记忆可以部分补偿通道的狭窄。

这仍然是工作假设，不是设计。它没有说明测量函数怎样产生、结构具体是什么形状、联想层如何实现，也没有证明它在 DeepSeek Flash 或任何选择模型上可行。

## 十、仍未决定

1. **提交点的地位**：它是由代码固定、结构不能编辑的边界，还是也属于结构、可以被学会和修改？前者更安全，但让“一切都是可编辑结构”出现一个例外；后者更彻底，但可能学会绕过自己的身体边界。（提出后尚未回答。）
2. **测量函数的产生**：由什么提出新的测量函数，什么决定它留下或安静；“由黑盒 LLM 根据残差提出、按穿透度与预测增益筛选”只是未确认的提议。草籽倾向于把它看作一种个体性、可发展的能力。
3. **输出类型**：浮点、整数还是 bool，目前没有证据。
4. **充分性的测量**：绝对充分性无法从内部测量；相对充分性（新增通道是否改善其它通道的预测）能否作为实际标准，尚未检验。
5. **穿透度的测量**：扰动重放能否可靠地度量“无常穿透”，以及静与应之间怎样取舍。
6. **局部更新规则**：在文本结构上，“使用时按误差改写”具体是什么操作；测量函数确定了误差落在哪里，但没有确定改写什么、改写多少。
