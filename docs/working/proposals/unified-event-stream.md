## 当前事实、已定语义与原型推论

以下记录的是**接线前的事实与设计推导**：当时 chatlog、每窗口 `context.Mailbox` 的未读水位、`oplog` 的 `opN`、`llm.Chat.chat` 的原生工具配对仍是并行机制；3b 第 6 步已提交（`0a3e579`），第 7 步待实际异步回调，4a 仅有未提交的投影入口，第一层可反查树没有落地。当前状态不能从这些日期快照推断，须看源码和[模型与工具](../../llm.md)。

1. 智能体的一次**完整子请求输出**（思考、正文、零到多个行动）是一个事件，只取一个 `YYYYMMDD-N` 统一号。行动派发前输出已有号；模型生成时不预知它。世界输入和自身输出在同一可索引信息流中，不按 `assistant` 字段、工具 API 角色、是否发送 QQ 决定留痕或分割。旧 `opN` 没有兼容承诺；不在此轮删除旧档。
2. 输入到达先按 mail FIFO 排队，**不预占正式号**；模型仅在完成当前输出后的子请求间隙读取，读取批次按 FIFO 分配正式号。D 生成时 B、C 已到但尚未读，认知顺序和编号为 D→B→C，不倒推模型在生成 D 时已知道 B。外部发生时间另记，不能替代阅读顺序。
3. **已定：**一个输入可承载多项返回，不为每个行动或每个结果机械另造事件；记录边界不由原生工具配对结构决定。**原型推论：**当同一输出中同名行动倒序返回，仅来源输出号不够消歧，随引用附输出内位置即可，不升级为第二套全局号；跨轮结果同理。
4. **已定：**`say` 的回声与动作必须可靠关联，不能按同文本/相邻时间猜。**原型推论：**早到回声先保留 `message_id`，返回带来相同 `message_id` 后才投影确认关系；关联以已确认关系投影为准，保留 echo 事件不表示已关联到某次行动。无对应返回或重复/歧义时不猜配、不误报成功。真实设备是否在全部路径提供足够关联事实，需到生产接入前核验。
5. **原型推论：**编号只给关系稳定的句柄，不强制载荷整块常驻上下文。思考/自言自语可沿现行轮间不保留策略从**后续模型视图**移除；大返回可经模型写的摘要或引用投影替换，同时保留可反查身份和因果关系。原型的摘要只是占位，**不是**生产压缩、磁盘删除、退休高度或树覆盖粒度的裁决。正文及行动描述不逐条取号。

## 本轮纯内存验收

不启动 Bot、不访问真实模型与 NapCat、不写运行数据：普通 dict/list、小函数和模拟派发已验证 D→B→C、未读不占号、一输出多行动单号及倒序批量返回、跨轮回调、早到/未确认 say 回声、跨日未读与截断前不派发。无原生配对的普通文本历史投影说明**信息流语义不依赖 LLF 或供应商工具配对**；尚未验证生产适配、真实模型理解这种历史投影的效果或安全执行边界。LLF、CQ 数组切换和中心化聊天软件均非当前前置。

## 最小接线次序（当前工作树已实施第 1–2 项；后续仍需验收）

第 1、2 项仅是**同一可用实施切片的准备顺序**：输入/输出正式编号与统一投影必须一起接线后切换，不能先激活半套身份并让它与旧 `oplog` 并行成为兼容契约。复用本轮证据；仅对静态阅读无法排除且会改变方案的交错/恢复疑点做针对性检查，不按反复跑绿的场景数验收。

1. 确认编号域及读批次快照边界；将 mail 的输入到达与读取分开、读取时赋正式号，保留当前窗口触发/预算/权限语义，不先推中心化。准备阶段不单独切换；已有合成证据涵盖未读不取号和 D 后 B/C 的 FIFO。
2. 在**完整输出已确认**而行动尚未派发的边界登记一个输出身份；一个响应含思考/正文/多个行动时一次登记，返回保留输出引用和仅必要的局部位置。针对截断、异常、重放的实际接线边界保证不重复执行；内存原型不证明生产持久性。
3. 核对真实发送 API 和回声的共同 `message_id`，遇到证据不足的早到回声/发送失败/重复消息/同内容并发发送时只针对性验证；确认关系以投影为准，未确认 echo 事实仍保留。不复活被回声接管删除的 `record_sent` 平行权威。
4. 将完整输入/输出身份与必要关系一起接入 4a 统一投影，再与 4b/4c 的选取、覆盖、反查生产者核对必要可追溯成员；处理思考与大返回增长点，不让新身份读不到索引。切换时同步退出旧 `oplog` 的新记录身份职责，不保留 `opN` 双轨兼容；旧数据处理另到站。

**到站才问语义：**编号域、输入记录边界、必要留痕与摘要/树的最小覆盖成员若确实影响使用者观察或引用，带证据与候选再问。跨日续号、重启重放、截断/崩溃恢复和 say 标识核对先由实施者从生产边界解决；仅遇到不能技术性消除且确实改变已定语义的分歧才上报。不要从实验偷推永久删除、自动总结、LLF 语法或聊天软件遗忘模型。
