# 记忆估值与索引演进

> 状态：研究提案；第一阶段只做离线派生测量，不改变投影、覆盖、读取或工具模块行为。
>
> 与[长期记忆离线回放实验](memory-replay-evaluation.md)的关系：本文提供可撤销的观察仪器，回放实验负责让柚子产生、使用并修订真实改动。任何分数都不定义“理想记忆”，也不成为实践反馈的前置门槛。
>
> 外部研究的核对见[记忆与自我演化研究地图](memory-and-self-evolution-research.md)：现有论文使用的是各自任务里的评分、反馈和启发式，没有提供可直接移植的普适记忆价值函数。

## 决定与边界

本提案从三个更底层的约束出发：

1. 经历可以持续增长，单次模型切片容量有限；过去若要继续影响现在，必须能被选择、压缩、寻址或重新展开。
2. 结构只有在后续求值中被实际消费、并改变取得有效下一状态的成本或结果时，它的实践价值才得到证据。
3. 系统产生的改动若只由同一个系统自评，容易形成自洽闭环；需要可重放比较、独立证据和未参与改动形成的新案例。

这三条是约束。最小描述长度、压缩进步、使用次数、图可达性、最短路径和干净切片对照都是候选测量方法。它们分别观察不同现象，不能互相替代，也不能合成为永久总分。

本文首先验证这些测量是否有辨别力。评分器不可用、某项指标失效或某种相关性不存在，都不阻断实践反馈主线；只表示不能用这件仪器解释相应现象。

## 四种需要分开的量

### 结构压缩

一个覆盖结论可以被看作成员原文的两段式编码：先传结论，再传给定结论后仍无法恢复的残差。对候选结论 `C`、成员 `E` 和基线上下文 `B`，候选测量为：

```text
Δ_mdl = L(E | B) - [L(C | B) + L(E | B, C)]
L(x | y) = -log₂ p(x | y)
```

`B` 不能额外直接包含目标成员 `E` 或候选结论 `C`，否则评分器只是重新读到了答案。比较已有节点时，单节点留一基线使用同一时刻的索引状态，移除候选节点 `C`，并把 `E` 只作为待评分目标；其余既有索引保持不变。其它节点若已经保存相同信息，本次测量会体现这种条件冗余。

若另行清除复述 `E`／`C` 的其它节点，应记录清除范围，并把这项比较称为信息消融，不与单节点留一混用。两种比较都不是拿空索引作基线，也不等于重新运行索引形成过程后的反事实结果；边际收益很小只说明候选在给定结构和协议下冗余，不证明它最初没有价值。

这个量回答的是：“在这套评分协议下，`C` 是否让 `E` 的表达更短？”它不直接回答：

- `E` 将来是否重要；
- `C` 是否容易由某个现实问题找到；
- 模型能否忠实地从 `C` 回到必要原文；
- `C` 是否改善未来行动；
- 真实请求的 token、工具调用和维护成本是否下降。

按 bit 计算结论成本可以防止逐字复制免费得分，但仍只测重建原文的压缩。许多未来任务只需要其中一个事实、关系或情绪背景，不需要复原整段文字；这类价值要由后续使用和实践结果补充。

### 压缩进步

同一残差在后续索引状态下是否越来越容易表达，可以作为“结构是否学到某种规律”的候选信号。比较必须同时计入新增索引本身的成本，并把参与形成的历史与未参与形成的新材料分开；在原材料上越拟合越好，不等于学到了可迁移规律。

高惊讶、低进步可能是随机 ID、URI、错字等噪声，也可能是电话号码、一次承诺或独特事件。因而压缩进步只帮助区分“可能可泛化的规律”与“暂时不可压缩的残差”，不能自动决定淡出。

### 结构可达与实际行走

正式号引用与覆盖成员都指向当时已经存在的事件；若核查没有例外，这部分事件关系可以按正式号形成向过去的 DAG。基于它可以派生：

- 当前入口下是否存在显式引用路径；
- 最短路径长度；
- 去掉某个节点后是否仍有其它通路；
- 多条路径是否共享同一个瓶颈；
- 一次实际检索读取了哪些节点和原文。

这些量只能描述**已建模边与给定入口下的结构**。当前入口可包括可见投影、hint 和已激活工具模块；但档案 `read_messages`、重新顺序阅读、未来增加的查询工具或模型凭语义重新发现，都可能在没有现成图路径时恢复内容。因此：

- 结构可达不等于能有效想起；
- 结构不可达不等于永远无法重新发现；
- 路径多不等于稳健，路径可能共享同一失效点；
- 实际走过表示暴露和使用，不自动给沿途每个节点因果信用。

已有回放已经否定“理论可达就足够”的强说法：目标证据有短的覆盖祖先链，模型仍进行了大范围枚举；加入语义下一跳后，实际路径才明显收敛。见[语义下一跳与实际反查](memory-replay-evaluation.md#2026-09-25语义下一跳与实际反查)。

### 实践使用与结果

`recall_events`、`event_links`、工具模块加载、空闲回收后重载、`^C` 和任务结果都可以成为观察信号，但没有固定价值方向：

- recall 多可能表示内容重要，也可能表示摘要失效或反复迷路；
- recall 少可能表示没人需要，也可能表示索引直接给出了答案，或入口根本找不到；
- `^C` 可能是失败反馈，也可能只是用户改变主意；
- 从未走过的路径只表示尚未观察到使用，不表示节点无价值。

使用信号必须带上当时问题、可见入口、观察时间、是否存在使用机会、实际读取内容和后来结果。它们用于解释一次实践，而不是直接累加成记忆分数。

## 索引与残差档案

当前原文保存在 chatlog 和事件流中，覆盖只改变默认投影。因此可以暂时区分：

- **索引结构**：结论、工具模块、hint 或其它能帮助未来构造切片的入口；
- **残差档案**：不可压缩、尚未整理或暂时没有入口的原始经历，仍可通过档案阅读与 `recall_events` 重新进入经历流。

“暂不提升进索引”不等于删除、退休或判定无价值。独特情景事实即使不可压缩，也可能需要一个很短的语义入口；入口是否值得存在，仍由后续使用检验。

程序性记忆也承受同一可读性压力：工具模块、link 和关于自身改动的记录，长期增长后是否能分层、追溯来源、比较版本并回退，目前尚未证明。本文只把它列为上限审计项，不预先把所有载体塞进同一图对象。

## 干净切片只是一种诊断

中心 agent 可以按需把同一问题交给较干净的子会话，并记录它实际读取了哪些索引节点。这个分叉用于观察“去掉长历史后，现有显式结构支持了什么”。

两边一致不表示正确：它们可能共同依赖错误摘要。两边不一致也不自动表示索引缺失：还可能来自随机性、角色提示、工具权限、中心上下文的锚定偏差或其它执行差异。

若要增强“索引遗漏”的解释，至少需要：

1. 两边先独立提交判断；
2. 用独立证据说明哪一处信息确实缺失；
3. 只向缺失一侧补回该材料；
4. 观察判断是否随之发生预期改变。

不规定复杂决策必须交给干净上下文，也不把定时子代理整理固化成流程。整理仍由具体问题、检索失败、实际 recall 或上下文压力触发。

## 评分器与派生数据

评分器的首个可行性问题是能否取得给定目标文本的条件 logprob。先用一次性离线探针检查当前 provider；若只支持生成 token logprob，再评估本地小模型是否值得作为有偏代理。不可用时停止这条测量路径，不为获得分数改写主模型协议。

若评分器可用：

- 评分函数保持普通函数形状，例如 `score_logprob(context, target) -> float`；
- 每项结果记录评分器及版本、prompt／切片构造协议版本，以及上下文和目标文本的内容摘要；评分器或评分协议改变后不直接混比分数，内容摘要用于追溯实际输入；
- 分数是可重算的派生数据，不写入事件事实层，不进入 chatlog；
- 首轮结果留在隔离实验目录，不先建立生产 `data/memory_scores` 或缓存格式；
- 评分器与主模型判断不一致是测量边界，不通过代码假装消除。

实际路径与使用信号也优先从既有事件流和实验轨迹派生。只有重复离线分析证明重算成本已经成为问题，才讨论持久索引或缓存。

## 最小实验顺序

### M0：测量语义校准

用少量合成材料检查仪器能否辨认已知反例：

- 可被短规则压缩的重复模式；
- 不可预测但后续任务明确需要的精确事实；
- 与任务无关的随机串；
- 图上有路径、但结论没有语义下一跳的节点；
- 与真实结论等长的错配／打乱结论。

真实结论若不能稳定优于等长错配结论，或者评分主要由目标泄漏决定，就停止当前 MDL 实现。M0 只校准测量语义，不证明实际记忆价值。

### M1：历史只读观察

从隔离回放轨迹核查能否重建某时刻的覆盖节点与冻结成员；核查失败就收窄为当前 checkpoint，不立即增加生产快照。

对小批覆盖节点按明确基线协议计算 `Δ_mdl`；只有存在多个可比索引状态时才计算压缩进步，缺少历史状态不阻断其它观察。把结果与带情境的后来使用、实际路径、证据支持和成本并列观察。相关性可以是正、负或混合；无显著关系首先表示当前代理尚未得到支持，显著相关也不能证明主动提高分数会改善实践。

### M2：接入可逆实践

复用[回放实验的首个已见练习](memory-replay-evaluation.md#实践反馈循环)：让柚子从“大范围反查”失败修改候选 Markdown 工具模块或索引做法，控制分支保持旧状态，候选分支精确加载本次运行产生的载体。

两边记录载体是否被消费、实际下一跳、首次命中、证据支持、具体化错误和成本。若 M0/M1 已有可用评分器，旁路计算压缩量但不向行动模型暴露；评分器未准备好也不阻止 M2。随后用未参与候选形成的新案例检查迁移，再由柚子根据完整新经历选择保留、修订或回退。

压缩与路径测量只能辅助解释候选改动。任务做法是否改善、产生改动的方法是否也得到改善，是两种不同主张，分别由实践反馈实验中的任务层与元层消费链验证；这些观察量不会因为参与自我演化实验就升级成通用价值函数。

## 进入运行时的门槛

测量支线的第一阶段只旁路观察：不因测量结果自动 cover、淡出、修改工具模块／hint，也不向主模型显示分数。M2 中候选载体的产生与加载沿用回放实验自己的隔离和提交协议，不属于分数驱动的自动改动。完成 M0/M1 后，只有某项派生量在多个实际案例中提供了模型仅靠现有轨迹难以获得的辨别信息，才讨论把它做成查询工具或可重算 hint；是否采取行动仍由中心 agent 决定。

暴露以后继续检查 Goodhart：若模型开始优化结论措辞以提高分数，但实际路径、实践结果或成本没有相应改善，就撤回这项暴露。分数本身提高不构成 Goodhart 的充分证据；需要观察它与原本要帮助的实践脱钩。

## 被排除的做法

- 不把 MDL、压缩进步、recall 次数或图指标定义成记忆价值；
- 不把多个观察量压成固定奖励或自动晋级阈值；
- 不因低分、未使用或结构不可达删除原文；
- 不引入向量库、常驻记忆 manager 或第二份可写真相源；
- 不强制定时整理、强制子代理、强制干净上下文决策；
- 不让评分器可用性阻断候选产生与实践反馈；
- 不把旧 chatlog 中参与者对旧回复的反应冒充为候选新回复的反事实结果。

## 推翻与收窄条件

| 观察 | 结论 |
|---|---|
| 无法取得可靠条件 logprob，本地代理成本也不值得 | 停止当前 MDL 实现；实践反馈继续 |
| 真实结论不能优于等长错配结论，或目标泄漏主导分数 | 当前切片／评分协议无辨别力，先修正或放弃 |
| 压缩分数上升，但必要精确事实更难取得或实践结果变差 | 禁止该分数承担此类任务的晋级依据 |
| recall 更多但完成更差，或 recall 更少却完成更好 | 否定“recall 次数单调代表价值” |
| 理论可达但持续无法定向取回 | 只保留结构可达解释；检查语义下一跳和实际行走 |
| 发现正式关系可以指向未来 | 放弃按正式号直接拓扑处理；另查是否真的形成环 |
| 干净切片分歧在补回疑似缺失材料后仍不随之改变 | 收窄“分歧来自索引遗漏”的解释 |
| 分数暴露后措辞得分上升，实践与成本不改善 | 撤回分数暴露，保留离线诊断 |

完成条件不是证明一个普适估值函数，而是知道每件仪器在什么情景下解释了什么、解释不了什么，并至少让一次候选改动经过“运行中产生—后续实际消费—重放比较—根据证据保留或回退”。
